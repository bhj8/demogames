# Demo Games

AI-assisted playable experiments and game design prototypes.

## Games

- `void_protocol_reference_load_gpt_20260812` — a first-person risk-routing experiment built from the VOID PROTOCOL design review.
- `voidprotocol_claude_20260812` — VOID PROTOCOL · 诊断构建: the original anchor-defense FPS rebuilt along the PlaySense improvement plan (frame A "diagnostic shooting"). Single-file, open `index.html` in a browser. Wave previews with wagers and early call-in, airdrop nodes, telegraphed melee, directional damage cues, spatial audio, honest shop math, seeded runs (`#12345` in the URL replays terrain and waves), anchor-funded revives, S/A/B/C grading.
- `symbiotic_fire_claude_20260813` — SYMBIOTIC FIRE · 共生火力：12 分钟一局的第一人称幸存者原型。每次重大进化都会让一种对应变异进入尸潮——你不只构筑自己，还亲手塑造本局必须面对的末日。六种共同变异、两层三选一、四阶段尸王、固定种子、调试面板。零资源文件，打开 `index.html` 即可。
