## 0. 本轮结论

当前需要补齐两条基础体验闭环：

1. 玩家受伤以后，要有一个可以主动争取的挽回机会，而不是只能等死。
2. 四面刷怪是幸存者类玩法的一部分；背后的怪不应被导演偷偷删掉，而应经历“接近预警 → 攻击预警 → 命中反馈”。

补给分为两个职责完全不同的系统：

- 医疗掉落：逆风兜底，解决恢复闭环。
- 战术空投：高频短时爽点，同时迫使玩家改变移动路线。

空投不能采用“一局固定三次、每次只强化十几秒”的组合。3 × 12 / 720 只有约 5% 强化覆盖率，玩家难以建立期待，也不值得单独做一整套系统。当前方案改为半固定、半动态，一局目标 7～9 次。

## P0：自适应医疗掉落

### 设计目的

医疗掉落不是击杀奖励，而是根据玩家当前状态提供“可以冒险争取的生还机会”。不要使用固定击杀数或纯随机概率，否则会出现顺风局满地医疗、逆风局迟迟不掉的反向反馈。

### MVP 规则

| 项目 | 参数 |
|---|---:|
| 触发生命线 | 当前生命 ≤ 70% |
| 单次恢复 | 最大生命的 20%（基础 120HP 时为 24HP） |
| 场上上限 | 1 个 |
| 掉落后存在 | 30 秒 |
| 两次掉落冷却 | 35 秒 |
| 拾取方式 | 玩家主动接触，不自动吸附 |
| 满血处理 | 不生成，不预存 |

使用隐藏的 medicalNeed：

- HP > 70%：medicalNeed 每秒衰减 0.5，最低为 0。
- 50% < HP ≤ 70%：medicalNeed 每秒 +0.45。
- 35% < HP ≤ 50%：medicalNeed 每秒 +1.0。
- HP ≤ 35%：medicalNeed 每秒 +2.0。
- medicalNeed ≥ 20、冷却结束且场上没有医疗物时：标记“下一只非召唤物敌人死亡后掉落医疗凝胶”。
- 成功生成后 medicalNeed 清零并开始冷却。

这样在不考虑冷却的情况下：

- 约 60% HP：持续受压约 44 秒后出现机会。
- 约 40% HP：约 20 秒。
- ≤35% HP：约 10 秒。

### 表现要求

- 医疗凝胶使用明确的绿色模型、地面光圈和竖向光柱。
- 出现和拾取必须有独立音效，不能复用经验球声音。
- HP < 50% 且医疗物在屏幕外时，显示绿色方向标；进入视野后隐藏。
- 拾取时播放现有 healflash，并显示“+24”或实际恢复数值。
- 医疗物落在被击杀敌人的位置，让玩家决定是否穿过尸群去拿。

### 与现有系统的关系

combat.js 中现有“创伤修复”是构筑升级效果，不是基础恢复系统，保留不动。新的医疗掉落是所有玩家都拥有的基础规则。

## P0：背后威胁三阶段提示

### 当前问题

当前 game.js 的威胁指示只标记 Boss、精英、冲锋状态和少数变种，普通近战丧尸不会提前提示。普通近战又是在接触范围内直接调用 hurtPlayer，因此当前红色方向扇形只能告诉玩家“刚才从哪里挨打”，无法避免第一次背后偷血。

不要继续依赖“更多怪刷在正面”解决这个问题。四面包围应保留，提示系统负责公平性。

### 阶段一：接近预警

将玩家周围划分为 8 个方向扇区，不为每一只怪单独画箭头。

纳入计算的敌人：

- 位于屏幕外；
- 距离玩家 ≤ 12 米，或按当前接近速度预计 2.5 秒内接触；
- 正在主动接近玩家。

表现规则：

| 状态 | 表现 |
|---|---|
| 12 米内的一般威胁 | 黄色方向弧 |
| 6 米内或预计 1.2 秒内接触 | 红色方向弧并脉冲 |
| 同扇区多只敌人 | 弧线更宽、更亮，不增加箭头数量 |
| 多方向同时逼近 | 最多显示威胁最高的 3 个扇区 |
| 进入摄像机视野 | 一般威胁方向弧隐藏 |

每个扇区聚合 threatScore。距离越近、预计接触时间越短、数量越多，分数越高。普通怪进入聚合提示；冲锋怪、Boss和正在释放特殊攻击的敌人继续保留独立的高威胁标记。

### 阶段二：攻击预警

普通近战敌人不能再“接触即扣血”。

增加 meleeWindup 状态：

1. 敌人进入攻击距离且攻击冷却结束。
2. 进入 0.5 秒攻击前摇，停顿并播放抬手/扑咬动作。
3. 前摇开始时播放一次有空间方向的近战预警声，对应方向弧立即变红。
4. 前摇结束时重新检查攻击距离；玩家已离开则攻击落空。
5. 命中后进入原有攻击冷却。

声音只在威胁升级或攻击前摇开始时播放一次，禁止持续蜂鸣。

### 阶段三：命中反馈

保留当前 damageFrom 的红色受伤扇形、hurtflash 和 0.85 秒持续时间。它只负责说明伤害来源，不再承担攻击预警。

### 刷怪原则

- 本轮不要用减少背后刷怪作为主要修复。
- 保留最小刷怪距离与出生保护，防止贴脸凭空生成。
- 威胁系统验收通过以后，再单独测试是否降低当前 65% 正面偏置；不要把两项改动混在同一次体验验收里。

## P1：半动态战术空投

### 设计目的

空投是反复出现的战术机会，不是三次固定播片。玩家看见它以后，应产生“是否偏离当前安全路线去抢一段强势期”的即时决策。

### 生成节奏

| 项目 | 参数 |
|---|---:|
| 首次空投 | 55 秒固定出现，用于教学 |
| 后续基础间隔 | 约 75 秒 |
| 最短间隔 | 45 秒 |
| 最长保底间隔 | 90 秒 |
| 单局目标 | 7～9 次 |
| 最后一轮保底 | 10:50 前仍未触发则强制投放 |
| 停止新投放 | 11:30 |
| 场上上限 | 1 个 |

后续空投使用 supplyCharge：

- 随时间稳定增长，约 75 秒自然充满。
- 普通击杀只提供很小的加速。
- 精英击杀提供明显加速。
- Boss击杀提供较大加速。
- 距上一次投放不足 45 秒时，即使充满也只进入排队。
- 距上一次投放达到 90 秒时，无视进度进入排队。
- 目标是让强势玩家略早拿到空投，但不能让弱势玩家永远拿不到。

具体击杀加速值全部放入 tune.js。首轮建议从“普通怪 +0.1%、精英 +6%、Boss +18%”开始，根据实测击杀速度校准至正常一局 7～9 次。

### 投放时机避让

supplyCharge 满后先进入 queued 状态，满足以下条件再真正投放：

- 当前不是升级三选一或共同变异选择。
- Boss登场演出结束至少 10 秒。
- 场上没有旧空投。
- 玩家没有正在生效的空投强化。

如果暂时不满足条件，保持排队，不清空进度。

### 空投流程

1. 在玩家 18～24 米外选择可到达位置。
2. 提前 5 秒播放坠落音效，并显示方向、距离和落点光柱。
3. 空投落地后存在 35 秒。
4. 空投周围提供三个颜色、图标明显不同的模块。
5. 玩家碰到其中一个即完成选择，其余两个立即消失。
6. 选择过程不暂停战斗。
7. 强化结束后才允许下一次已排队空投落地。

必须区分三个时间：

- 坠落预告：5 秒。
- 落地可拾取：35 秒。
- 拾取后强化：约 14 秒。

### 三个首发模块

#### 1. 过载供弹

- 持续 14 秒。
- 弹匣不减少。
- 不允许进入换弹状态；正在换弹则立即结束并补满。
- 射速 +20%。
- “无限子弹”指无限弹匣，不是增加备用弹药。

#### 2. 肾上腺素

- 持续 14 秒。
- 移动速度 +35%。
- 拾取时立即恢复一次冲刺。
- 冲刺冷却 -50%。
- 不额外改变摄像机 FOV，避免眩晕。

#### 3. 相位护盾

- 最长持续 15 秒。
- 吸收最多 60 点玩家伤害，先耗尽或先到时均结束。
- 伤害先扣护盾，再进入玩家生命结算。
- 护盾受击使用蓝色反馈，不能误用红色 hurtflash。
- 护盾不是回血，不提高最大生命。

### HUD

- 强化生效时显示图标、名称和秒级倒计时。
- 空投屏幕外时显示青色方向标和距离；进入视野后只保留世界光柱。
- 空投即将消失的最后 5 秒快速闪烁。
- 三种强化不可叠加；当前规则通过“强化期间不落下一个空投”避免替换问题。

## 追加 P0：弱点 / 爆头完整闭环

> 追加设计：Codex（OpenAI），2026-08-13  
> 协作说明：本节只追加在原文末尾，不修改上文。Claude 不需要中断当前正在实现的任务；完成手头工作后，再按本节继续处理。

### 现状与根因

爆头并非单纯“反馈不明显”，当前判定存在一个会让弱点实际上无法触发的碰撞逻辑问题：

- 子弹先通过 segCylinder 命中敌人的外层圆柱，命中点的水平半径约为 enemy.radius + 0.09 × bulletScale。
- 随后弱点判定却要求命中点到敌人中心的水平距离小于 enemy.radius × 0.85。
- 对普通丧尸而言，圆柱命中半径约 0.55，弱点要求小于 0.391；两者不可能同时成立。
- 因而当前 weak 在正常射击中理论上始终为 false，配置中的 weakpointMult 2.0 和“瞄准模块”基本无法生效。

此外，所有敌人共用 0.86 × height 的弱点高度也无法与模型稳定对应。普通丧尸大致接近，但冲撞怪的头部明显更低且向前突出，Boss比例也不同。

### P0.1：重新实现弱点碰撞

不要继续从身体圆柱的命中点反推头部。

建议：

1. 每种敌人模板增加独立 weakpoint 配置：
   - yRatio：相对身高；
   - forwardOffset：沿敌人朝向的前后偏移；
   - radiusRatio：相对身高或敌人半径；
   - enabled：是否拥有弱点。
2. 子弹扫掠时分别检测“头部球”和“身体碰撞体”。
3. 射线与头部球相交则判定 weak；否则再按身体圆柱结算普通命中。
4. 头部球的世界位置必须跟随敌人的 pos、face 与 height。
5. 普通、重型、吐酸者、冲撞精英和 Boss 分别配置，禁止继续共用一个 0.86 常量。
6. 由头部命中绕过骨板的现有规则继续保留。

可以采用独立 segSphere；若身体圆柱仍包住头部，不能因为身体圆柱的交点更早就吞掉头部判定。粗略碰撞体只是代理，玩家准星穿过可见头部球时应优先按弱点处理。

### P0.2：建立玩家能直接感知的爆头反馈

当前爆头与普通命中的火花颜色过于接近，且只有空间化命中音，没有准星反馈。新增：

| 事件 | 反馈 |
|---|---|
| 普通命中 | 白色小型准星 X，约 70ms |
| 弱点命中 | 更大的金色准星 X，约 130ms，短暂向外弹开 |
| 弱点击杀 | 红金色击杀标记或二段脉冲 |
| 弱点命中世界反馈 | 命中点产生明显的金白粒子爆发，而不是仅替换浅黄色 |
| 弱点声音 | 独立、短促、非空间衰减的中央确认音，避免被枪声和尸潮声淹没 |

正式界面不建议显示所有普通伤害数字，会在 9 发/秒和高怪物密度下刷屏。可以只显示金色弱点伤害数字；调试模式必须能够显示全部实际伤害。

### P1：首轮数值

| 项目 | 当前 | 首轮建议 |
|---|---:|---:|
| 基础枪械伤害 | 12 | 12 |
| 基础弱点倍率 | 2.0 | 2.5 |
| 瞄准模块每级 | +0.5 | +0.5 |
| 瞄准模块满级倍率 | 3.0 | 3.5 |

这样开局普通丧尸 30HP 时：

- 身体命中需要 3 发；
- 弱点命中 12 × 2.5 = 30，可以 1 发击杀。

它会在第一分钟建立非常明确的规则：“瞄头确实有价值”。后续敌人生命成长后不必保证永远一枪击杀，但弱点仍应显著缩短击杀时间。

先修复判定并完成反馈，再评价 2.5 是否过高；不要在 weak 永远无法触发的现状下继续调倍率。

### 调试与数据

增加：

- Debug 模式显示敌人弱点球。
- stats.weakHits：弱点命中数。
- stats.weakKills：弱点击杀数。
- Debug 伤害数字明确区分普通伤害和弱点伤害。
- 测试面板提供静止的普通、重型、吐酸、冲撞和 Boss 靶子。
- 若保留散布，测试弱点碰撞时应提供无散布调试枪，避免把弹道随机误判为碰撞错误。

### 验收清单

- [x] 使用无散布调试枪连续射击普通丧尸可见头部中心，弱点判定稳定触发。
- [x] 射击躯干中心不会误判为弱点。
- [x] 普通、重型、吐酸、冲撞与 Boss 的弱点球均与可见头部对齐。
- [x] 冲撞怪转身、移动和冲锋时，弱点球仍跟随其头部方向与偏移。
- [x] 玩家不看伤害数字，也能仅凭准星与声音区分普通命中、弱点命中和弱点击杀。
- [x] 开局普通丧尸满足“身体 3 发、弱点 1 发”的首轮目标。
- [x] 瞄准模块升级后，实际弱点伤害与卡面倍率一致。
- [x] 骨甲尸身体正面仍被骨板抵消，弱点命中仍能正确绕过骨板。
