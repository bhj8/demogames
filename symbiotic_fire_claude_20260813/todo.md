## 0. 本轮结论

当前需要补齐两条基础体验闭环：

1. 玩家受伤以后，要有一个可以主动争取的挽回机会，而不是只能等死。
2. 四面刷怪是幸存者类玩法的一部分；背后的怪不应被导演偷偷删掉，而应经历“接近预警 → 攻击预警 → 命中反馈”。

补给分为两个职责完全不同的系统：

- 医疗掉落：逆风兜底，解决恢复闭环。
- 战术空投：高频短时爽点，同时迫使玩家改变移动路线。

空投不能采用“一局固定三次、每次只强化十几秒”的组合。3 × 12 / 720 只有约 5% 强化覆盖率，玩家难以建立期待，也不值得单独做一整套系统。当前方案改为半固定、半动态，一局目标 7～9 次。

## P0：自适应医疗掉落

### 设计目的

医疗掉落不是击杀奖励，而是根据玩家当前状态提供“可以冒险争取的生还机会”。不要使用固定击杀数或纯随机概率，否则会出现顺风局满地医疗、逆风局迟迟不掉的反向反馈。

### MVP 规则

| 项目 | 参数 |
|---|---:|
| 触发生命线 | 当前生命 ≤ 70% |
| 单次恢复 | 最大生命的 20%（基础 120HP 时为 24HP） |
| 场上上限 | 1 个 |
| 掉落后存在 | 30 秒 |
| 两次掉落冷却 | 35 秒 |
| 拾取方式 | 玩家主动接触，不自动吸附 |
| 满血处理 | 不生成，不预存 |

使用隐藏的 medicalNeed：

- HP > 70%：medicalNeed 每秒衰减 0.5，最低为 0。
- 50% < HP ≤ 70%：medicalNeed 每秒 +0.45。
- 35% < HP ≤ 50%：medicalNeed 每秒 +1.0。
- HP ≤ 35%：medicalNeed 每秒 +2.0。
- medicalNeed ≥ 20、冷却结束且场上没有医疗物时：标记“下一只非召唤物敌人死亡后掉落医疗凝胶”。
- 成功生成后 medicalNeed 清零并开始冷却。

这样在不考虑冷却的情况下：

- 约 60% HP：持续受压约 44 秒后出现机会。
- 约 40% HP：约 20 秒。
- ≤35% HP：约 10 秒。

### 表现要求

- 医疗凝胶使用明确的绿色模型、地面光圈和竖向光柱。
- 出现和拾取必须有独立音效，不能复用经验球声音。
- HP < 50% 且医疗物在屏幕外时，显示绿色方向标；进入视野后隐藏。
- 拾取时播放现有 healflash，并显示“+24”或实际恢复数值。
- 医疗物落在被击杀敌人的位置，让玩家决定是否穿过尸群去拿。

### 与现有系统的关系

combat.js 中现有“创伤修复”是构筑升级效果，不是基础恢复系统，保留不动。新的医疗掉落是所有玩家都拥有的基础规则。

## P0：背后威胁三阶段提示

### 当前问题

当前 game.js 的威胁指示只标记 Boss、精英、冲锋状态和少数变种，普通近战丧尸不会提前提示。普通近战又是在接触范围内直接调用 hurtPlayer，因此当前红色方向扇形只能告诉玩家“刚才从哪里挨打”，无法避免第一次背后偷血。

不要继续依赖“更多怪刷在正面”解决这个问题。四面包围应保留，提示系统负责公平性。

### 阶段一：接近预警

将玩家周围划分为 8 个方向扇区，不为每一只怪单独画箭头。

纳入计算的敌人：

- 位于屏幕外；
- 距离玩家 ≤ 12 米，或按当前接近速度预计 2.5 秒内接触；
- 正在主动接近玩家。

表现规则：

| 状态 | 表现 |
|---|---|
| 12 米内的一般威胁 | 黄色方向弧 |
| 6 米内或预计 1.2 秒内接触 | 红色方向弧并脉冲 |
| 同扇区多只敌人 | 弧线更宽、更亮，不增加箭头数量 |
| 多方向同时逼近 | 最多显示威胁最高的 3 个扇区 |
| 进入摄像机视野 | 一般威胁方向弧隐藏 |

每个扇区聚合 threatScore。距离越近、预计接触时间越短、数量越多，分数越高。普通怪进入聚合提示；冲锋怪、Boss和正在释放特殊攻击的敌人继续保留独立的高威胁标记。

### 阶段二：攻击预警

普通近战敌人不能再“接触即扣血”。

增加 meleeWindup 状态：

1. 敌人进入攻击距离且攻击冷却结束。
2. 进入 0.5 秒攻击前摇，停顿并播放抬手/扑咬动作。
3. 前摇开始时播放一次有空间方向的近战预警声，对应方向弧立即变红。
4. 前摇结束时重新检查攻击距离；玩家已离开则攻击落空。
5. 命中后进入原有攻击冷却。

声音只在威胁升级或攻击前摇开始时播放一次，禁止持续蜂鸣。

### 阶段三：命中反馈

保留当前 damageFrom 的红色受伤扇形、hurtflash 和 0.85 秒持续时间。它只负责说明伤害来源，不再承担攻击预警。

### 刷怪原则

- 本轮不要用减少背后刷怪作为主要修复。
- 保留最小刷怪距离与出生保护，防止贴脸凭空生成。
- 威胁系统验收通过以后，再单独测试是否降低当前 65% 正面偏置；不要把两项改动混在同一次体验验收里。

## P1：半动态战术空投

### 设计目的

空投是反复出现的战术机会，不是三次固定播片。玩家看见它以后，应产生“是否偏离当前安全路线去抢一段强势期”的即时决策。

### 生成节奏

| 项目 | 参数 |
|---|---:|
| 首次空投 | 55 秒固定出现，用于教学 |
| 后续基础间隔 | 约 75 秒 |
| 最短间隔 | 45 秒 |
| 最长保底间隔 | 90 秒 |
| 单局目标 | 7～9 次 |
| 最后一轮保底 | 10:50 前仍未触发则强制投放 |
| 停止新投放 | 11:30 |
| 场上上限 | 1 个 |

后续空投使用 supplyCharge：

- 随时间稳定增长，约 75 秒自然充满。
- 普通击杀只提供很小的加速。
- 精英击杀提供明显加速。
- Boss击杀提供较大加速。
- 距上一次投放不足 45 秒时，即使充满也只进入排队。
- 距上一次投放达到 90 秒时，无视进度进入排队。
- 目标是让强势玩家略早拿到空投，但不能让弱势玩家永远拿不到。

具体击杀加速值全部放入 tune.js。首轮建议从“普通怪 +0.1%、精英 +6%、Boss +18%”开始，根据实测击杀速度校准至正常一局 7～9 次。

### 投放时机避让

supplyCharge 满后先进入 queued 状态，满足以下条件再真正投放：

- 当前不是升级三选一或共同变异选择。
- Boss登场演出结束至少 10 秒。
- 场上没有旧空投。
- 玩家没有正在生效的空投强化。

如果暂时不满足条件，保持排队，不清空进度。

### 空投流程

1. 在玩家 18～24 米外选择可到达位置。
2. 提前 5 秒播放坠落音效，并显示方向、距离和落点光柱。
3. 空投落地后存在 35 秒。
4. 空投周围提供三个颜色、图标明显不同的模块。
5. 玩家碰到其中一个即完成选择，其余两个立即消失。
6. 选择过程不暂停战斗。
7. 强化结束后才允许下一次已排队空投落地。

必须区分三个时间：

- 坠落预告：5 秒。
- 落地可拾取：35 秒。
- 拾取后强化：约 14 秒。

### 三个首发模块

#### 1. 过载供弹

- 持续 14 秒。
- 弹匣不减少。
- 不允许进入换弹状态；正在换弹则立即结束并补满。
- 射速 +20%。
- “无限子弹”指无限弹匣，不是增加备用弹药。

#### 2. 肾上腺素

- 持续 14 秒。
- 移动速度 +35%。
- 拾取时立即恢复一次冲刺。
- 冲刺冷却 -50%。
- 不额外改变摄像机 FOV，避免眩晕。

#### 3. 相位护盾

- 最长持续 15 秒。
- 吸收最多 60 点玩家伤害，先耗尽或先到时均结束。
- 伤害先扣护盾，再进入玩家生命结算。
- 护盾受击使用蓝色反馈，不能误用红色 hurtflash。
- 护盾不是回血，不提高最大生命。

### HUD

- 强化生效时显示图标、名称和秒级倒计时。
- 空投屏幕外时显示青色方向标和距离；进入视野后只保留世界光柱。
- 空投即将消失的最后 5 秒快速闪烁。
- 三种强化不可叠加；当前规则通过“强化期间不落下一个空投”避免替换问题。

## 验收清单

### 医疗

- [ ] HP > 70% 时不会无意义地产生医疗物。
- [ ] HP ≤ 35%、医疗不在冷却时，继续战斗并完成至少一次有效击杀后，约 10～15 秒内获得恢复机会。
- [ ] 场上永远不超过一个医疗物。
- [ ] 医疗物能被看见、听见，残血时能从屏幕外找到。
- [ ] 恢复量随最大生命变化，拾取不会溢出最大生命。

### 空投

- [ ] 第一次约 55 秒出现，后续不是固定时间表。
- [ ] 普通完整对局正常出现 7～9 次，而不是 3 次。
- [ ] 任意相邻两次不会短于 45 秒；不存在超过 90 秒没有机会的情况，事件避让除外。
- [ ] 预告、可拾取时间、Buff持续时间三者互不混用。
- [ ] 三种强化均有明显体感，且结束后完整恢复原始参数。
- [ ] 空投不会与选择界面、Boss登场或上一段空投 Buff 抢占注意力。

### 背后威胁

- [ ] 普通丧尸从正后方逼近时，在第一次受伤前先出现方向提示。
- [ ] 高危状态至少提供 0.5 秒视觉与空间声音预警。
- [ ] 玩家在前摇结束前离开攻击距离时不会受伤。
- [ ] 后方大量敌人被聚合为方向压力，不会生成几十个箭头。
- [ ] 特殊敌人的独立高危提示仍然清晰。
- [ ] 命中后的红色方向反馈继续正确指向伤害来源。

## 非目标

本轮先不要：

- 把医疗或空投塞进升级三选一。
- 给空投增加额外的“开启后立刻刷一波怪”惩罚。
- 扩充第四、第五种空投强化。
- 通过继续增加正面刷怪比例掩盖背后提示问题。
- 在第一版就追求最终数值；先保证完整闭环和调试可观测性。

完成顺序：背后威胁 P0 → 医疗 P0 → 空投 P1 → 12分钟完整试玩调参。
