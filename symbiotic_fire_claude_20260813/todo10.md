## 0. 本轮为什么必须推翻 Build 上层规则

todo5 的实现证明系统可以运行，但人工试玩暴露了三个根本问题。

### 0.1 升级不够强，甚至会让玩家变弱

todo5 实现记录中的固定靶场数据：

| 状态 | 6秒伤害 |
|---|---:|
| 基线 | 1140 |
| 齐射 | 465 |

齐射多发弹丸、同步多耗弹药，最终不是成长，而是明显降级。其他模块也大量使用“给一点收益，再用同等代价抵消”的设计。

吸血鬼 Like 的升级不是等价改装：

> **大升级必须提供超额收益；代价只负责制造距离、弹药、生命或站位风险，不能把收益吃干净。**

### 0.2 玩家看不懂卡牌

并联供弹、尾迹稳流、谱系深度改写、动势导流、载荷继承等词汇属于实现语言，不属于玩家语言。

玩家卡面只允许表达：

1. 得到了什么。
2. 需要付出什么。
3. 当前数值会变成多少。

如果专业玩家不能在三秒内读懂，卡牌直接判定失败。

### 0.3 当前是配方表，不是化学系统

当前实现包含：

- S/A/B 反应矩阵。
- 大量专属组合名称。
- 28 对组合逐对审计。
- 针对组合手写的终点爆破、分裂波、重型机关炮等行为。
- 动态显示“你将形成某某融合”。

这等于设计师先算完所有结果，玩家只负责触发配方。

todo10 改成：

> **只实现一组基础分子和统一攻击规律。组合结果由这些规律自然产生，不命名、不评级、不逐对写专属代码。**

某些组合很强、某些普通、某些不搭，都是允许的。幸运局明显强于平均局，也是产品目标。

## 2. V3 六个核心分子

核心分子负责改变枪如何发射、传播或结算。首次获得是大升级；再次获得只提高同一张卡的等级，不产生新名称。

所有数值都是首轮灰盒建议，最终以人工试玩和持续输出测试调整。

### 2.1 多发

**玩家卡面：**

> 每枪多发2颗，只多消耗1发。  
> 距离越远，伤害衰减越明显。

首轮规则：

- [ ] 1级：总弹丸数3，单次耗弹2。
- [ ] 此后每级弹丸数 +1。
- [ ] 每两次后续升级，单次耗弹才 +1。
- [ ] 6米内每颗弹丸保留完整伤害。
- [ ] 6～14米逐渐衰减；14米外保留约45%单弹伤害。
- [ ] 弹丸比耗弹增长更快，近距离必须获得真正的超额输出。
- [ ] 每颗弹丸独立携带爆炸、穿透、弹射、重弹与所有大选择倍率。

禁止：

- [ ] 不得再次实现成“多发一颗就多耗一颗”。
- [ ] 不得用统一伤害预算把多颗弹丸重新压回一颗子弹的总伤害。
- [ ] 不得用玩家感知不到的散布惩罚冒充风险。

### 2.2 爆炸

**玩家卡面：**

> 每次命中都会伤害周围敌人。

首轮规则：

- [ ] 每一次真实子弹命中都产生爆炸。
- [ ] 1级爆炸伤害建议为本次命中伤害的35%～45%。
- [ ] 1级半径建议约2.5米。
- [ ] 升级提高爆炸伤害与半径，仍然只叫“爆炸”。
- [ ] 多发的每颗弹、穿透的每次命中、弹射的每次命中都能自然触发爆炸。
- [ ] 重弹、双倍装药、贴脸、远射等倍率自然作用于爆炸。
- [ ] 对Boss和精英保留直击与爆炸价值。

禁止：

- [ ] 不再使用“整根攻击只有一份爆炸预算”抵消组合收益。
- [ ] 不再改成只有终点才爆炸。
- [ ] 不实现多点爆破、终点爆破、跳爆等专属配方名称或分支。

### 2.3 穿透

**玩家卡面：**

> 子弹穿过2个敌人，后续伤害逐次降低。

首轮规则：

- [ ] 1级额外穿透2个目标。
- [ ] 每次后续命中保留约80%伤害。
- [ ] 每级增加1次穿透，并可小幅提高保留比例，上限不得超过95%。
- [ ] 每一次穿透命中都完整进入统一命中流程：直接伤害、爆炸、弹射。
- [ ] 穿透只负责让主弹继续向前，不等待穿透结束后才允许弹射。

### 2.4 弹射

**玩家卡面：**

> 每次命中都会向附近敌人弹射。  
> 每次继续弹射，伤害都会降低。

核心纠偏：

> **弹射不是“穿透结束后再转弯”，而是主弹每次命中时同时向侧面产生一条弹射链。主弹仍可继续穿透。**

首轮规则：

- [ ] 主弹每次直接命中都尝试寻找一个附近新目标。
- [ ] 1级拥有1次弹射，建议伤害约为55%。
- [ ] 每级增加1次继续弹射。
- [ ] 每次后续弹射约保留上一跳70%的伤害，首轮参考序列为55%、38%、27%、19%。
- [ ] 弹射链继承爆炸、重弹、双倍装药以及距离和弱点等通用伤害规则。
- [ ] 弹射链自身只能继续当前链，不能从每次弹射命中再生成一条全新的并行弹射链。
- [ ] 主弹穿透5个敌人时，可以从5次主弹命中分别产生5条弹射链；这是允许的自然强化学反应。
- [ ] 使用全局事件和对象上限防止性能失控，不使用针对“穿透×弹射”的专属伤害补丁。

### 2.5 重弹

**玩家卡面：**

> 单发伤害大幅提高。  
> 射速降低，并且每枪多消耗1发。

首轮规则：

- [ ] 1级直接伤害及其爆炸、弹射等伤害倍率建议约2.2倍。
- [ ] 基础射速建议降至约65%。
- [ ] 单次耗弹 +1。
- [ ] 升级继续提高伤害；部分等级可以缓解射速损失。
- [ ] 枪声、后坐动画、枪口反馈和命中反馈必须明显变重。
- [ ] 后坐动画只用于表达冲击，不作为数值惩罚。
- [ ] 重弹不是预设火箭筒；它仍然可以与多发、穿透、弹射和超频同时存在。

### 2.6 超频

**玩家卡面：**

> 持续射击时，射速不断提高。  
> 停火或换弹后重新开始升速。

首轮规则：

- [ ] 持续射击逐渐提高射速，存在明确上限。
- [ ] 1级峰值建议约 +60%～80%射速。
- [ ] 升级提高升速速度和峰值，上限集中配置。
- [ ] 停火或换弹后重置或快速衰减。
- [ ] HUD、枪声和枪口密度清楚显示当前档位。
- [ ] 超频不额外消耗弹药。
- [ ] 超频不额外添加散布和后坐惩罚。
- [ ] 玩家持续开火已经承担命中控制、观察威胁和频繁换弹的自然代价，不再重复惩罚。
- [ ] 超频只改变发射频率，不手写“重型机关炮”“分裂波”等组合结果。

## 3. 七个真正改变行为的大选择

大选择必须改变距离、站位、瞄准、生命风险、弹药风险或目标选择。正常游玩必然自动触发的条件，不允许作为大选择。

大选择首次获得后可通过品质或重复抽取提高倍率，但不产生新名称。

### 3.1 贴脸

**卡面：**

> 7米内所有伤害大幅提高。  
> 远距离伤害降低。

首轮建议：

- 7米内约 ×1.7。
- 7～14米平滑过渡。
- 14米外约 ×0.7。
- 距离倍率作用于直接伤害、爆炸和弹射。

玩家选择：冒着被尸潮包围的风险换取真正高输出。

### 3.2 远射

**卡面：**

> 15米外所有伤害大幅提高。  
> 近距离伤害降低。

首轮建议：

- 15米外约 ×1.7。
- 7～15米平滑过渡。
- 7米内约 ×0.7。
- 地图必须提供可以维持远距离的路线，但不能永久安全。

玩家选择：主动拉开尸潮并寻找长街、屋顶和纵深射线。

### 3.3 爆头

**卡面：**

> 爆头会放大这次攻击的全部伤害。  
> 身体伤害降低。

首轮建议：

- 弱点命中的整次攻击家族约 ×2。
- 身体伤害约 ×0.8。
- 爆头产生的爆炸和弹射继承该次攻击倍率。
- 卡面与准星必须明确提示弱点命中。
- 不使用“弱点回响、载荷继承”等术语。

玩家选择：牺牲无脑扫射效率，换取精准攻击的爆发。

### 3.4 低血

**卡面：**

> 生命低于40%时，所有伤害大幅提高。

首轮建议：

- 低于40%生命时约 ×1.8。
- 高于阈值时没有收益，不额外削弱。
- HUD清楚显示激活状态。
- 恢复和护盾不会偷偷改变判定；只读取当前生命比例。

玩家选择：主动维持危险生命线，还是治疗并失去火力。

### 3.5 站桩

**卡面：**

> 保持不动时，伤害持续提高，最高翻倍。  
> 移动后立即清空。

首轮规则：

- [ ] 玩家落地且水平移动速度低于阈值时开始积累。
- [ ] 约0.5秒后开始生效。
- [ ] 每隔固定时间继续提高，直到总伤害最高约 ×2。
- [ ] 允许转动视角和瞄准，不因转头清空。
- [ ] 一旦产生真实位置移动，立即清空全部层数。
- [ ] HUD显示简单、连续、带上限的火力条。
- [ ] 不实现成“静止一下只强化下一发”；它必须是持续提升、存在上限的状态。

玩家选择：在尸潮中冒险占住位置，还是移动求生。

### 3.6 双倍装药

**卡面：**

> 每枪消耗双倍弹药。  
> 这次攻击造成的所有伤害翻倍。

锁死规则：

- [ ] 在其他耗弹规则结算后，将本次总耗弹直接 ×2。
- [ ] 直接伤害、爆炸、穿透后续命中和弹射伤害统一 ×2。
- [ ] 不增加其他隐藏惩罚。
- [ ] 不以“爆炸预算、派生预算”重新削回倍率。
- [ ] 弹匣、换弹、节弹和击杀装填会自然改变该选择的实际持续DPS。
- [ ] 弹匣不足本次耗弹时按统一开火规则处理，不允许免费透支。

玩家选择：换取接近双倍的瞬时火力，但弹匣更快打空、换弹真空更频繁。

### 3.7 专注目标

**卡面：**

> 持续命中同一个敌人时，伤害越来越高。  
> 一段时间没有命中该目标后重置。

首轮规则：

- [ ] 只由玩家直接射出的主弹选择和维持专注目标。
- [ ] 爆炸、弹射和穿透命中其他敌人不会把专注目标切走。
- [ ] 连续命中同一目标逐层提高对该目标的全部伤害。
- [ ] 首轮建议每层 +10%，最高约 +100%。
- [ ] 约0.8～1.2秒没有再次直接命中该目标时重置。
- [ ] 直接瞄准并命中新的主要目标时切换并从零开始。
- [ ] 目标头顶显示非常简单的层数或锁定标记。

玩家选择：继续扫群，还是持续盯住精英和Boss兑现高单体输出。

### 3.8 明确删除的大选择

- [ ] 停火蓄力：删除。
- [ ] 血弹：删除，避免玩家因持续按住射击轻易越过安全线，并与低血形成失控绑定。
- [ ] 高处射击：删除，当前地图路线不足以让它形成稳定且公平的选择。
- [ ] 空仓爆发：删除，正常玩家本来就会不断打空和换弹。
- [ ] 高速开火：删除，正常玩家本来就会不断移动。
- [ ] 所有“第N发”“下一颗子弹”式选择继续禁止用于当前高速武器。

## 4. 七个武器小升级

小升级允许是清楚的数值成长。它们不需要假装成新机制，也不创造奇怪名称。

### 4.1 威力

> 所有伤害提高。

- [ ] 首轮每级建议 +20%～25%。
- [ ] 同时作用于直接、爆炸和弹射，但在归因中仍分开统计。

### 4.2 射速

> 基础射速提高。

- [ ] 首轮每级建议 +20%～25%。
- [ ] 射速提高会自然加快耗弹和换弹频率，不额外补偿。

### 4.3 扩容

> 弹匣容量大幅提高。

- [ ] 首轮每级建议 +40%～60%。
- [ ] 使用向上取整并保证UI显示真实最终容量。
- [ ] 多发、重弹和双倍装药持有越多，扩容的持续DPS价值自然越高。

### 4.4 快装

> 换弹时间大幅缩短。

- [ ] 首轮每级建议缩短25%～35%。
- [ ] 设置最小换弹时间，避免无限趋近于零。
- [ ] 高耗弹Build中允许它成为最强小升级之一。

### 4.5 弱点

> 爆头伤害提高。

- [ ] 只提高弱点倍率，不添加新触发名词。
- [ ] 与“爆头”大选择自然相乘。

### 4.6 节弹

> 有概率返还这次攻击额外消耗的弹药。

- [ ] 基础必耗的1发不能被返还。
- [ ] 只针对多发、重弹、双倍装药等产生的额外耗弹。
- [ ] 首轮概率建议约20%～25%，升级提高概率。
- [ ] UI直接显示本次节省的弹药数量。

### 4.7 击杀装填

> 击杀敌人会把弹药装回当前弹匣。

- [ ] 每次有效击杀返还1发。
- [ ] 同一次根攻击设置返还上限，首轮建议最多3发，防止大范围清屏瞬间装满。
- [ ] 返还不超过弹匣上限。
- [ ] 爆炸和弹射击杀沿用统一伤害归因，自然触发，不为组合写例外。

### 4.8 明确不进入小升级池

- [ ] 稳定：怪物密度过高，散布和后坐变化几乎没有决策价值。
- [ ] 大弹：弹体尺寸与击退在当前战斗中感知不足。
- [ ] 范围：作为爆炸自身升级处理，不拆成额外通用卡。
- [ ] 弹速、搜索范围、单独击退、单独射程等感知不足的参数卡。

## 5. 九个机动、生存与资源升级

这些与武器卡处于同一个三选一池，但属于小升级。它们不得成为地图基本路线的通行证。

1. **强心**：最大生命提高，并立即恢复相应生命。
2. **再生盾**：一段时间不受伤后恢复有限护盾。
3. **近杀回血**：近距离击杀恢复少量生命，设置每秒恢复上限。
4. **二次冲刺**：增加一次冲刺储能。
5. **连续机动**：有效跑墙后刷新一次空中冲刺；每次滞空链最多触发一次。
6. **落地冲击**：高速落地产生范围伤害和击退，强度读取真实落地速度。
7. **跑墙护盾**：完成一定距离的跑墙后获得临时护盾。
8. **冲刺撞击**：高速冲刺可以伤害并推开普通敌人；同一敌人有触发冷却。
9. **拾取强化**：扩大经验、医疗与空投拾取范围。

明确删除：

- [ ] 冲刺装填：正常战斗频繁冲刺，缺乏选择且与弹药循环过度自动绑定。
- [ ] 空中稳定：当前散布和后坐不会显著影响尸群命中率。
- [ ] 纯移动速度百分比卡：由 todo6 的基础机动尺度负责，不占Build选择。

## 6. 统一三选一、大小升级与品质

### 6.1 一局结构

12分钟目标：

- [ ] 总选择次数首轮目标16～20次，根据经验曲线动态产生，不按固定时间强行弹窗。
- [ ] 最后90秒停止升级，让完成Build连续发挥。
- [ ] 每局平均获得4～6个不同核心分子。
- [ ] 每局平均获得1～2个大玩法选择。
- [ ] 其余选择用于重复强化、小升级、机动和生存。
- [ ] 不再限制最多3个核心分子。
- [ ] 获得5个不同核心分子后，新分子的出现权重下降，但不完全锁死，允许幸运局继续扩展。

### 6.2 同一个池

玩家永远只看到同一种三选一：

- 新核心分子：大升级。
- 新玩法选择：大升级。
- 已有分子升级：小升级或高品质升级。
- 武器、机动、生存：小升级。

不得分别弹出“大升级、小升级、地图升级”三个不同界面。

保底：

- [ ] 第一次选择固定提供3个不同核心分子。
- [ ] 前4次选择结束前，至少能够获得2个核心分子。
- [ ] 连续2次三选一没有任何大升级，下一次至少出现1张。
- [ ] 高耗弹达到每枪2发以上时，提高扩容、快装、节弹和击杀装填的出现权重，但不强制玩家选择。

### 6.3 品质只代表升级量

品质不再创建新名字、新分支和新规则。

- 普通：提高1级。
- 稀有：提高2级。
- 史诗：提高3级。
- 传奇：提高4级。

首轮概率建议：

- 普通55%。
- 稀有30%。
- 史诗12%。
- 传奇3%。

保底建议：

- [ ] 连续4次选择没有出现史诗或传奇，下一次至少出现1张史诗。
- [ ] 连续12次选择没有出现传奇，下一次至少出现1张传奇。
- [ ] 传奇多发仍然只叫“多发”，只是一次获得更多等级。
- [ ] 不再出现谱系改写、派生预算改写、空心爆破、折射棱等品质专属术语。

## 7. 玩家可读性

### 7.1 卡面

每张卡最多显示：

1. 一个普通词名称。
2. 一句绿色收益。
3. 一句红色代价或触发条件。
4. 当前值 → 选择后数值。

示例：

**多发**

> 每枪弹丸：3 → 4  
> 单次耗弹：2发；远距离衰减更快

**站桩**

> 不动时伤害持续提高，最高100%  
> 移动后立即清空

**双倍装药**

> 所有伤害 ×2  
> 每枪总耗弹 ×2

禁止玩家卡面出现：

- 根弹、次级弹、谱系。
- 载荷、预算、消费者。
- 深度、继承系数、事件节点。
- S级反应、融合名。
- 没有实际战斗含义的世界观包装词。

### 7.2 HUD

- [ ] 只显示当前核心分子名称与等级，例如“多发 Lv3、爆炸 Lv2、穿透 Lv1”。
- [ ] 大玩法选择显示简单状态：距离、低血、站桩层数、专注层数、超频档位。
- [ ] 不显示组合名称。
- [ ] 不要求玩家理解底层攻击图。
- [ ] 结算页继续分别显示直接、爆炸、弹射等伤害，以及弹药消耗、换弹时间占比和有效开火时间。

## 8. 统一自然反应规则

V3 仍可复用 attack-graph 的谱系、归因和性能上限，但对玩家和卡池隐藏全部实现术语。

### 8.1 攻击顺序

1. 结算本次基础耗弹与多发、重弹、双倍装药产生的额外耗弹。
2. 多发生成所有主弹。
3. 计算贴脸、远射、低血、站桩和威力等通用倍率。
4. 主弹命中结算直接伤害。
5. 每次主弹命中独立触发爆炸。
6. 每次主弹命中独立产生一条弹射链。
7. 主弹若仍有穿透次数，继续沿原方向前进并衰减。
8. 弹射链按自身次数继续寻找新目标并逐跳衰减。
9. 超频只更新下一次开火间隔。
10. 击杀装填、归因和反馈读取统一伤害事件。

### 8.2 两类属性

传播属性：

- 多发。
- 穿透。
- 弹射。

伤害与条件属性：

- 爆炸。
- 重弹。
- 超频。
- 贴脸、远射、爆头、低血、站桩、双倍装药、专注目标。
- 所有武器小升级。

传播属性决定攻击到达多少目标；伤害与条件属性自然作用于这些命中。不得为两张卡的组合建立独立技能ID。

### 8.3 性能上限不是伤害预算

保留：

- 单帧效果事件上限。
- 每秒效果事件上限。
- 场上弹丸上限。
- 单根攻击对同一目标的重复命中上限。
- 弹射链最大跳数。

删除或停用：

- 为了让组合看起来“平衡”而平均分配的统一爆炸伤害预算。
- 为了让多发不变强而平均分配的统一总伤害预算。
- 针对某一对组合的专属伤害折算。

如果达到性能上限：

- 优先合并同帧视觉和音效。
- 再限制对象数量。
- 不能静默削减玩家已经看见并理解的伤害。
- Debug必须显示被拒绝的事件数量和来源。

### 8.4 强组合的处理原则

- [ ] 允许幸运组合明显强于中位Build。
- [ ] 不因为某组三卡伤害高就立刻写专属削弱。
- [ ] 只有无限递归、性能崩溃、完全压制所有其他选择或破坏12分钟流程时才干预。
- [ ] 调整优先级：基础分子数值 → 通用衰减 → 全局安全上限。
- [ ] 最后才考虑组合例外；任何例外必须在 todo10 实现记录中写明原因。

## 9. 强度重算

### 9.1 统一计算方式

所有升级必须同时测量：

- 瞬时DPS。
- 10秒持续DPS。
- 一弹匣总伤害。
- 打空时间。
- 换弹时间占比。
- 每秒弹药消耗。
- 单体伤害。
- 群体有效伤害。
- 弱点命中收益。

持续输出按完整循环计算：

> **持续DPS = 一弹匣总伤害 ÷（打空时间 + 换弹时间）**

扩容和快装必须按当前实际单次耗弹重新计算价值。高耗弹Build中，它们可以自然超过普通威力升级。

### 9.2 单卡最低标准

- [ ] 大升级在其正确场景中，实际输出或生存效率至少提高40%～60%。
- [ ] 小升级通常提高15%～30%的持续战斗价值。
- [ ] 不允许任何大升级在自己的目标场景低于基线。
- [ ] 多发必须分别在3米、8米、15米测试，证明近距离超额、远距离衰减。
- [ ] 双倍装药必须同时验证瞬时接近×2，以及因换弹频率上升导致的持续输出折损。
- [ ] 扩容、快装、节弹必须在每枪1、2、4发耗弹下分别测试。
- [ ] 超频必须验证峰值提升真实可见，且没有新增人工惩罚。
- [ ] 站桩满层必须值得玩家冒险停住。
- [ ] 专注目标必须对精英和Boss有效，对普通尸群不成为必选。

### 9.3 整局成长目标

首轮体验目标：

| 时间 | 中位Build相对基础有效输出 |
|---|---:|
| 约3分钟 | 2～3倍 |
| 约6分钟 | 4～8倍 |
| 约9分钟 | 10～15倍 |
| 完整幸运Build | 中位Build的1.5～2.5倍 |

- [ ] 后期普通怪应该成片死亡。
- [ ] 后期压力主要来自数量、精英、包围、路线和换弹真空，不靠普通怪变成血牛。
- [ ] 玩家不断升级时，普通怪击杀时间不能持续恶化。
- [ ] 怪物血量曲线必须在玩家中位Build与弱势Build实测后再调整。

## 11. 验收标准

### 11.1 三秒可读

- [ ] 玩家三秒内可以复述每张卡的收益和代价。

- [ ] 不存在只有实现者看得懂的节点名称。
- [ ] 重复升级直接显示等级与数字变化。

### 11.2 自然组合

- [ ] 多发的每颗弹自然爆炸、穿透并触发弹射。
- [ ] 穿透每次命中自然产生爆炸与侧向弹射。
- [ ] 重弹和双倍装药自然放大直接、爆炸和弹射。
- [ ] 超频自然提高所有按开火频率发生的效果。
- [ ] 以上结果均来自统一流程，不存在对应的融合技能ID。
- [ ] HUD和卡面不为组合命名。
- [ ] 删除任意组合名称表后，战斗结果不发生变化。

### 11.3 弹药与DPS

- [ ] 多发在近距离明显强于基线，而不是像当前版本降到465/1140。
- [ ] 高耗弹Build中扩容和快装能成为高价值DPS选择。
- [ ] 双倍装药的瞬时输出、持续输出和换弹真空符合卡面承诺。

### 11.4 完整一局

- [ ] 一局通常获得4～6个核心分子，而不是被锁成3模块模板。
- [ ] 连续两局不会因为固定配方自然长成同一把枪。
- [ ] 玩家可以用一句普通话描述本局，例如“近距离三发、每发都会爆并往旁边弹”。
- [ ] 玩家不需要背融合名称。
- [ ] 至少出现一部分明显强于平均值、值得记住的幸运局。
