## 1. 空投奖励

当前除“过载供弹”外，其他空投缺乏拾取价值。

- **过载供弹**：保持现有效果。
- **暴走针**：约 14 秒内提高移速、射速，并大幅加快换弹。
- **强袭盾**：获得护盾；护盾存在期间提高所有伤害。

三种空投按一次增益窗口内带来的击杀与经验收益校准，不能再让过载供弹成为唯一有效选择。

## 2. 滑索 Bug

滑索目前不可用：玩家触发后无法正常滑行。

修复为可正常双向滑行；玩家能够从任意一端完成一次通行即验收通过。本轮不继续扩展地图设计。

## 3. 变异僵尸节奏

本轮暂不调整，保留现状，继续试玩观察。

## 4. 等级与经验节奏

当前强 Build 打到结尾通常只有 17 级，成长次数不足。

- 玩家等级与“已选择升级次数”彻底分离，禁止互相覆盖。
- 动态经验修正只能为落后进度提供追赶，玩家领先时不得反向提高升级需求。
- 普通局目标为 19～20 级，强 Build 可达到 22～24 级。
- 10:30 后不再弹出升级选择，避免打断最后阶段战斗。

## 5. 升级防误触

升级界面出现后：

- 前 2 秒卡片和键盘快捷键均不可选。
- 清空弹出前持续按住的鼠标状态。
- 2 秒结束后，玩家必须先松开左键，再重新点击，才能完成选择。

## 6. 贴脸与远射平衡

直接替换现有近似对称的收益曲线：

- **贴脸**：7 米内约 ×2.0；14 米外约 ×0.6。
- **远射**：15 米外约 ×1.4；7 米内约 ×0.8。

贴脸风险更高，因此必须拥有明显更高的收益上限；远射更安全，收益应低于贴脸。

### 顺手修的两个 bug（不在 todo11 里，Bao 试玩时报的）

**出生点在地图外面、半个身子在地里。**
`frame()` 的 dt 只钳了上界 `Math.min(0.05, ...)`，没钳下界。点「开始」时代码里
`last = performance.now()`，而 rAF 回调拿到的 `now` 是这一帧**开始**的时间戳，
可能早于那次点击 —— 第一帧 dt 为负，整个世界倒着跑一帧：`G.time` 变成 −0.01，
所有 `x -= dt` 的计时器反向增长（包括 `st.jumpBuf`，所以没人按空格也会冒出
一次缓冲跳跃），位置跟着反向积分，标签页被节流过就能把玩家甩出地图。
证据：一个 `jump` 事件在 `G.time=-0.01` 触发，而 `MOVE.onJump` 一次没被调用、
`KEY.Space=false`。

**§2 滑索。** 机制没坏，是**玩家跳上去的那一下把自己甩下来**：挂索时上一次
跳跃的输入缓冲还在，而滑行中「按跳 = 主动脱离」，第 1 帧就脱开。
实测走上去滑满 177 帧到终点，跳上去只滑 1 帧、离终点还有 52m —— 而正常玩家
都是跳上去的。另外 `nearestDevice` 原来只量 a 端，站在另一头怎么都吸不上，
按 §2 补成双向。六次测试（三条索 × 两端）全部滑满全程。

### §4 节奏：真正的病根不在漂移项

Bao 的判断比原文准。除了删掉「领先时加价」，更要命的是**定价公式本身**：

```
need = 最近经验收入 × progressBase
```

收入越高，单次需求等比例越高，两边**精确抵消** —— 不管 Build 多强，次数永远
钉在目标值上。实测佐证：给机器人一套强 Build，多打死 15% 的怪，
**升级次数一次都没多**（19 → 19）。

改成一半按收入、一半锚在**本局开局收入**上：

```
need = (0.65 × 当前收入 + 0.35 × 开局收入) × progressBase
```

`rateWeight = 0.65` 是按目标反解的，不是拍的：次数比 = `m / (w·m + 1−w)`，
要「收入 1.8 倍的强 Build 多拿约 18% 次数（19.5 → 23）」，解出 w ≈ 0.657。
锚取本局开局收入而不是写死常数，以后再调武器数值它会自己跟着走。

配套：`targetCount 18→20`、`hardFloor 25→20`、`progressBase 46→64`。

**实测**：十个种子跑满 12 分钟，普通局稳定 **19 次**（目标 19~20）。
强 Build 那一档机器人分辨不出来 —— 它跑出来的「强 Build」只比普通局多赚 12%
经验，而真人手里的强 Build 远不止 —— **这一档只能由 Bao 试玩确认**。

### §1 空投

§1 写明「过载供弹保持现有效果」，所以是把另外两个**抬上来**，不是削它。
中位高耗弹 Build、一次增益窗口内的循环 DPS（相对无强化）：

| 空投 | 循环 DPS | 另外给什么 |
|---|---:|---|
| 过载供弹 | 237% | 弹匣不减，全程不换弹 |
| 暴走针 | 194% | 移速 +35%、冲刺冷却 −50% |
| 强袭盾 | 125% | **150 点护盾**（超过满血 120，实打实一条命） |

暴走针真正的价值是**换弹 −62%** —— 高耗弹 Build 有一半时间耗在换弹上，
砍掉它才等价于「更多输出」。强袭盾按 Bao 定的保命型走，DPS 低是应该的，
它的收益在那 150 点盾上。

### §5 防误触

三道闸，缺一不可：

1. 前 2 秒完全不可选，**卡面变暗 + 倒计时**（不可选必须看得见，否则像卡死）
2. 弹出瞬间清掉「正在开火」状态
3. 锁解开后还必须**先松开左键再重新按**

第 3 条是关键：只做第 1 条的话，按住不放的玩家会在 2 秒整那一刻被选掉。
自动化测试验证：0.0s / 1.0s / 2.3s 三次点击全部挡住，松开后再点才选中；
而正常的一次新点击（mousedown→mouseup→click）天然满足第 3 条，不影响手感。
