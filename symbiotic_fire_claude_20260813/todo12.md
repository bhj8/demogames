## 1. 刷怪节奏（本轮核心）

**症状**：前期 DPS 没问题，但 8 分钟只有 5 级，精英怪迟迟不出现。

### 1.1 一个被实测否掉的诊断（保留记录）

最初的判断是「缺口按全图算，所以地图很满而玩家面前很空」：

```
target   = 10 + 80 × (t/720)^0.9     ← 全图在场目标数
interval = 3.0 / (1 + 缺口 × 1.2)     ← 缺口越大刷得越快
```

于是把缺口改成按【玩家 35m 内】算。**实测把它否掉了**：

| | 玩家身边平均在场 | 前 3 分钟 | 最低 |
|---|---|---|---|
| 按全图算（原样） | 47.1 | 19.8 | 8 |
| 按身边算（改动） | 33.8 | 17.7 | 4 |

按身边算等于给刷新加了**第二道上限**：全图总量上不去，最终能走到玩家
身上的怪反而更少。这条路本身是错的，代码回到按全图算，
`Director.countNear()` 留下来当**量尺**（`_stability.html` 用它回答
「玩家面前到底有没有怪可打」）。

### 1.2 真正起作用的两个数

前期不够打，是 `targetBase` 和 `maxInterval` 的事 —— 开局全图只允许
10 只，打空之后要 3 秒才补一只。

- [x] `targetBase` 10 → **16**，`maxInterval` 3.0 → **1.6**。

实测（跑动机器人，5 种子，A/B 只改这两个数）：

| | 前 3 分钟身边在场 | 前 3 分钟击杀 | 全程升级次数 |
|---|---|---|---|
| 改前 | 12.9 | 233 | 19 |
| 改后 | **17.7** | **278** | 19 |

后期不受影响：`targetCoef` 与 `aliveCap` 没动，k 一大 `targetBase` 就淹没了。

### 1.3 允许的隐性帮助

**Bao 明确否决了时间保底方案**：

> 「这样玩家就会偷懒……绝对不允许玩家什么事情都不做经验就会涨。
> 要是玩家发现了，最优解就是找个地方挂机。」

所以经验只能来自击杀，能做的只有**折扣**。

- [x] 第 2～5 次进化的需求打 75 折（第 1 次走固定的 `firstNeed`）。

实测（种子 11，只改这一个数）：

```
关：22 80 115 144 183 …   8 分钟前 13 次
开：22 60  89 120 159 …   8 分钟前 14 次
```

第 2 次早 20 秒，第 5 次早 24 秒，**全程次数不变**（都是 19）——
这是让前期滚起来，不是多送升级。

### 1.4 还没解释掉的差距

机器人在改动前就已经是「8 分钟 13～14 次」，而 Bao 的实机是「8 分钟 5 级」。
这个差距**至今没有在模拟里复现出来**，所以上面三项都是在缩小已知的病灶，
不是已经定位到 Bao 遇到的那一个。下一局试玩要盯的就是这条。

## 2. 恶魔卡（红色稀有层）

**定位**：不是更强的卡，是**改写规则**的卡 —— 每张都必须拿掉一样东西。

**投放**：一局最多 2 张，4 分钟后进池，出现时**独占第三格**（前两格照常走保底）。
不分级 —— 「Lv2 自动瞄准」没有含义，拿过之后直接退出牌池。

| 恶魔卡 | 得到 | 失去 |
|---|---|---|
| 自动瞄准 | 子弹自动追踪准星最近的敌人 | 不能爆头、射速 −25% |
| 大弹鼓 | 弹匣 +500% | 换弹时间 +200% |
| 玻璃大炮 | 造成伤害 ×3 | 受到伤害 ×3（护盾同样按 ×3 扣） |
| 独弹 | 单发伤害 ×16 | 弹匣永远只有 1 发 |
| 开镜达人 | 开镜时伤害/射速/精度各 +60% | 移速 ×0.45；不开镜散布 ×8 |

数值说明：

- **独弹 ×16 不是 ×11。** 弹匣变 1 发后每发都要背一次 1.55s 换弹，
  ×11 算下来循环 DPS 只有 +8%（73.7 → 79.5），拿到手毫无感觉。
  ×16 → 115.6，即 **+57%**，并且天然吃快装（配满快装 +73%）。
- **自动瞄准与爆头不做互斥**（Bao 决定）。两张一起拿会只剩身体 ×0.7
  的惩罚，那是玩家自己的选择。
- **独弹 + 大弹鼓一起拿是纯亏**，也不拦 —— 卡面写的是「永远 1 发」，
  代码里独弹放在最后覆盖，验收里专门测了这一条。

实现要点：

- 追踪目标在**扣扳机那一刻锁死**，一根攻击共用一个。每颗弹丸各自找目标的话，
  多发一枪会散成扇子追七个人 —— 那不是自动瞄准，是自动分裂。
- 玻璃大炮的 ×3 加在 `hurtPlayer` 的**第一行**，在护盾之前 ——
  放在护盾之后就变成「盾能挡三倍伤害」，这张卡就没有代价了。
- 开镜达人的移速与散布**每帧**变，所以在 `BUILD.tick` 里覆写 `G.derived`，
  不折进 `derive()`（那只在 recompute 时算一次）。伤害那一项走 `victimMul`，
  和站桩同类。

## 3. 局部优化

- [x] **击杀回弹改百分比**：每次击杀返还 `当前弹匣 × 3%/级`，浮点累加
      （零头留在 `ctx.loadFrac`，不四舍五入吞掉），
      单根攻击返还 ≤ 本枪耗弹的一半（上限也是小数 —— 取整到 1 发的话，
      耗弹 1 发的枪每杀一个就回半个弹匣，这张卡会变成无限弹药）。
- [x] **强心**：最大生命 **+25%/级**，并且**立即回满**（不是回补差额）。
      按等级从基线整体重算，顺带保证幂等。
- [x] **滑索改手动**：取消自动吸附，进入范围显示 `[E] 上索`，按 E 才挂。
      提示半径 4.2 → 6.0m —— 误吸的风险没有了，够不着才是新问题。
- [x] **空投/医疗指引常驻**：方向标不再「进视野就隐藏」，改成进视野后
      淡到 50% 不抢视线。医疗包的 50% 血门槛一并删掉 ——
      它只在 ≤70% 生命时才会掉，存在本身就说明玩家需要它。
- [x] **远程怪克制**：占场上敌人比例 ≤ 20%（抽到超额的退回普通感染者）；
      同一时刻最多 3 只在开火（超额的继续等，不是取消攻击）。
