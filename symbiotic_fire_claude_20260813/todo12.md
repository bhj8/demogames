## 1. 刷怪节奏（本轮核心）

**症状**：前期 DPS 没问题，但 8 分钟只有 5 级，精英怪迟迟不出现。

**诊断**（读代码确认，不是猜）：

```
target   = 10 + 80 × (t/720)^0.9     ← 全图在场目标数
interval = 3.0 / (1 + 缺口 × 1.2)     ← 缺口越大刷得越快
```

`缺口` 是**按全图**算的。8 分钟时全图目标 66 只，但它们散在 220×180m 的城里。
玩家把身边打空，全图数字仍然是满的 → 缺口 ≈ 0 → 刷新退回 3 秒一只的涓流。
**地图很满，玩家面前很空。** 这就是「DPS 还行但经验跟不上」的机制。

**Bao 明确否决了时间保底方案**：
> 「这样玩家就会偷懒……绝对不允许玩家什么事情都不做经验就会涨。
> 要是玩家发现了，最优解就是找个地方挂机。」

所以经验只能来自击杀，改的是**让玩家身边有怪可打**。

- [ ] 缺口改成按【玩家周围 engageRadius 内】算，不再按全图。
- [ ] 全图 target 降级成纯性能上限，不再驱动刷新速度。
- [ ] 允许的隐性帮助（Bao 同意）：**前 4 次升级需求打 75 折**，之后回 100%。
      这是折扣不是白送 —— 不打怪照样一级都不涨。

## 2. 恶魔卡（红色稀有层）

**定位**：不是更强的卡，是**改写规则**的卡 —— 每张都必须拿掉一样东西。

**投放**：一局最多 2 张，4 分钟后进池，出现时**独占第三格**（前两格照常走保底），
算作「武器侧卡」。

| 恶魔卡 | 得到 | 失去 |
|---|---|---|
| 自动瞄准 | 子弹自动追踪准星最近的敌人 | 不能爆头、射速 −25% |
| 大弹鼓 | 弹匣 +500% | 换弹时间 +200% |
| 玻璃大炮 | 造成伤害 ×3 | 受到伤害 ×3（护盾同样按 ×3 扣） |
| 独弹 | 单发伤害 ×16 | 弹匣永远只有 1 发 |
| 开镜达人 | 开镜时伤害/射速/精度各 +60% | 移速 ×0.45；不开镜散布 ×8 |

数值说明：

- **独弹 ×16 不是 ×11。** 弹匣变 1 发后每发都要背一次 1.55s 换弹，
  ×11 算下来循环 DPS 只有 +8%（73.7 → 79.5），拿到手毫无感觉。
  ×16 → 115.6，即 **+57%**，并且天然吃快装（配满快装 +73%）。
- **自动瞄准与爆头不做互斥**（Bao 决定）。两张一起拿会只剩身体 ×0.7 的惩罚，
  那是玩家自己的选择。
- **击杀回弹按当前弹匣百分比算**，不按基础弹匣（Bao 决定）：
  「用户用输出的选项换取了续航，没问题的。」

## 3. 局部优化

- [ ] **击杀回弹改百分比**：每次击杀返还 `当前弹匣 × 3%/级`，浮点累加，
      单根攻击返还 ≤ 本枪耗弹的一半。
- [ ] **强心**：最大生命 +25%/级，并且**立即回满**（不是回补差额）。
- [ ] **滑索改手动**：取消自动吸附，进入范围显示 `[E] 上索`，按 E 才挂。
      顺带解决「路过被强制拽走」。
- [ ] **空投/医疗指引常驻**：现在进视野就隐藏，一转头就找不到。
      改成方向标永远显示；目标在视野内时改为世界光柱 + 距离数字。
- [ ] **远程怪克制**：占场上敌人比例 ≤ 20%；同一时刻最多 3 只在开火。
