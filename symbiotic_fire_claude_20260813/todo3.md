## 0. 产品结论

本轮不是“给平地加几栋楼”，也不是“多塞一些升级卡”，而是让两根核心支柱彼此咬合：

1. **空间支柱**：玩家在街道、建筑立面和屋顶之间持续流动，用跑酷摆脱尸潮、创造射击窗口，再主动回到危险区域抢经验和资源。
2. **构筑支柱**：玩家只面对一种进化三选一；基础变异、连接、融合、地图能力和终局规则通过品质与前置条件进入同一个池，并在一局内逐步发生乘法反应。

目标产品表达：

> 一款 12 分钟一局，在立体丧尸城市中飞檐走壁、边移动边射击，并把随机变异组合成失控武器机器的第一人称尸潮幸存者。

统一进化的设计总句：

> **一个选择仪式，一条动态节奏，多种品质深度；保底负责让普通局成立，概率负责制造偶尔离谱的神仙局，地图允许玩家用冒险轻微操纵概率。**

目标参考比例：

- 60%《消逝的光芒》：自然、宽容、容易读懂的第一人称攀爬与翻越。
- 25%《泰坦陨落 2》：移动具有连续动量，并且移动和射击能够同时发生。
- 15%《虐杀原形》：玩家不被普通墙体和高低差轻易阻断，具有轻度超人感。
- 《Apex》作为地图元素参考：滑索、跳板、楼层连接和清晰的城市路线设计。
- 《吸血鬼幸存者》只作为“杀怪—经验—进化—成型”的节奏底座；本项目的差异点是第一人称枪械、立体路线和玩家可轻微操纵下一次随机。

本轮总循环：

**杀怪赚经验 → 统一进化三选一 → 形成新的构筑联动 → 利用立体路线放大联动 → 冒险争夺地图资源并影响下一抽 → 尸潮获得对应戏剧化变化 → 继续杀怪**

空间中的短循环：

**街面收割 → 尸潮合围 → 登墙上楼 → 移动射击 → 屋顶抢资源 → 特殊感染者封锁高处 → 跳回街面继续收割**

核心戏剧冲突：

- 留在地面更容易获得经验、医疗和密集击杀，但更容易被包围。
- 前往高处可以创造空间和射击角度，但高处不能成为永久安全区。
- 停下来更容易精确射击，持续移动才更容易活下来。
- 地图奖励越诱人，路线风险越高；玩家可以冒险改善下一抽，但不能直接购买确定答案。
- 普通局必须稳定成型；欧皇局允许突破平均强度，形成值得记住的失控时刻。
- 敌人的共同进化负责制造戏剧，不得把玩家刚抽到的好运等额抵消。

### 0.1 不可破坏的产品规则

- [ ] 全局只有一种会暂停战斗的正式选择界面：进化三选一。
- [ ] 每次先抽本次品质，再生成三张同品质卡；禁止白、蓝、紫混在同一组选项里。
- [ ] 选择质量由当前构筑和前置条件保证，品质只决定这一次有多深，不决定有没有一个能用的选项。
- [ ] 保底只抬高坏运气下限，不对连续紫色、金色进行反向压制。
- [ ] 地图、空投、Boss 与风险行为只影响下一次进化或直接发放已预告奖励，不再开启第二套三选一。
- [ ] 没有紫色、金色时，基础变异之间也必须自动发生反应，保证平均局能够完整成型。
- [ ] 高品质选择应是显著净收益；敌人变化增加挑战与叙事感，但不能让玩家后悔抽到高品质。

## 2. P0：玩家基础机动系统

所有关键路线必须由基础能力完成，不能要求玩家随机抽到某张卡才能离开街道或抵达屋顶。

### 2.1 基础动作

- [x] 跳跃。
- [x] 自动翻越汽车、护栏、矮墙和低障碍。
- [x] 自动抓边并爬上阳台、平台和屋顶。
- [x] 短距离垂直登墙，用于抵达可抓取边缘。
- [x] 短距离横向墙跑。
- [x] 地面与空中共用一次方向冲刺。
- [x] 奔跑后滑铲。
- [x] 滑索、跳板等地图机动装置。
- [x] 第一版不设置跑酷耐力。
- [x] 第一版不造成坠落伤害。
- [x] 落地可以有镜头、枪模、音效和尘土反馈，但不能产生长时间硬直。

### 2.2 输入原则

建议保持低操作负担：

- Space：普通跳跃；持续按住时，根据环境自动翻越、抓边或登墙。
- Shift：沿当前移动输入方向冲刺；在空中时变为空中冲刺。
- 奔跑中按蹲伏：进入滑铲。
- 滑索使用现有交互键或近距离自动吸附，二者择一并保持全局一致。
- 墙跑通过“空中靠近可跑墙面＋持续前进”自动进入，不增加独立墙跑键。

玩家的主要决策应该是“走哪条路线”，而不是记忆复杂按键组合。

### 2.3 第一轮建议参数

所有数值必须放入集中配置，并允许 Debug 热调：

| 参数 | 首轮建议 |
|---|---:|
| 重力 | 20～22 m/s² |
| 起跳速度 | 8.0～8.5 m/s |
| 土狼时间 | 0.12 秒 |
| 跳跃输入缓存 | 0.15 秒 |
| 自动翻越高度 | ≤1.2 米 |
| 抓边攀爬高度 | ≤2.4 米 |
| 垂直登墙持续 | 0.45～0.65 秒 |
| 横向墙跑上限 | 0.9～1.2 秒 |
| 空中冲刺次数 | 1 次，接触稳定地面后恢复 |
| 空中冲刺持续 | 0.16～0.22 秒 |
| 滑铲基础持续 | 0.55～0.8 秒 |

这些只是首轮起点。手感目标比具体数值更重要：动作要宽容、不断流、不需要精确对准一个像素的边缘。

### 2.4 移动与枪械不得互相中断

- [x] 跳跃、下落、墙跑、滑索和空中冲刺期间允许射击。
- [x] 跳跃、下落和普通墙跑期间允许换弹继续推进。
- [x] 自动翻越与抓边动画尽量短，不长时间锁枪。
- [x] 准星在空中仍然可用，不施加严重的空中散布惩罚。
- [ ] 冲刺与滑铲如何影响射击沿用统一规则，不允许同类动作表现不一致。
- [x] 移动状态只向 WeaponPresentation 提供姿态与速度数据，不把枪械表现重新堆回移动代码。
- [x] 现有冲刺无敌帧必须重新核对；地面与空中共用同一充能，不允许重复恢复形成永久无敌。

### 2.5 碰撞与容错

- [x] 使用胶囊体或等价连续碰撞，避免高速冲刺穿墙、穿楼板。
- [x] 抓边检测包含前向探测、顶部空间检测和可站立面检测。
- [x] 头顶空间不足时不得强行攀爬进模型。
- [x] 墙跑只允许在标记为可墙跑的近垂直表面触发。
- [x] 离开墙面时给予短暂输入宽限，减少动作无故中断。
- [x] 被边缘或小装饰卡住时优先自动越过，而不是完全停下。
- [ ] Debug 显示 grounded、airborne、vault、mantle、wallRun、dash、slide 等移动状态。

## 3. P0：一张完整的三层立体城市地图

本轮直接制作完整 12 分钟地图，但控制为一个高密度街区，不扩张成开放世界。

### 3.1 总体规模

- 水平范围建议约 70×70 米，试玩后再根据敌人密度调整。
- 垂直分为三层：
  - 街道层：0～3 米。
  - 建筑中层：约 4～10 米。
  - 屋顶层：约 12～20 米。
- 三层提供的有效路线面积大于当前平面地图，但任意位置都不应长时间看不到敌人。
- 第一版不制作大量真实楼层，建筑主要提供外立面、屋顶和短通道。

### 3.2 四个识别地标

- [x] 中央十字路口：主要街面战斗区和高密度经验区。
- [x] 立体停车楼：宽缓坡道、楼层绕行和快速跳楼路线。
- [x] 在建大楼与吊车：墙跑、脚手架、吊车桥和楼间跨越。
- [x] 医院或商场停机坪：高层空投点、精英事件和终局高压区域。

地标需要明显不同的轮廓、颜色和灯光，使玩家不看小地图也能判断自己所在方向。

### 3.3 路线结构

- [x] 每个高度层至少存在两条可以连续循环的路线。
- [x] 三层之间至少设置 6 个有效连接点。
- [x] 每个主要屋顶至少拥有两个玩家出口。
- [x] 每个主要屋顶至少拥有一种敌人入侵方式。
- [x] 不允许出现只有玩家能上、普通威胁永远无法到达的狙击台。
- [ ] 不允许大量死胡同；有死胡同时必须放置明确奖励或快速离开方式。
- [ ] 玩家从任意主要区域出发，10 秒左右应能找到至少两种高度变化选择。
- [x] 所有关键路线都能用基础动作完成。
- [ ] 机动升级只能提供捷径、效率和战斗收益，不能解锁唯一必经道路。

### 3.4 环境路线元素

- 街道：车辆、公交车、集装箱、路障、店铺雨棚。
- 中层：广告牌、空调机、阳台、消防梯、脚手架、连廊。
- 屋顶：通风设备、水箱、吊车、停机坪、屋顶缺口。
- 快速装置：滑索、跳板、坠落缓冲棚、吊车钢索。
- 可破坏或变化元素第一版使用预设状态切换，不做真实物理破坏模拟。

### 3.5 可读性语言

- [x] 可翻越边缘使用统一的高亮边条。
- [x] 可墙跑表面使用统一的油漆、划痕或灯带。
- [x] 滑索、跳板和攀爬锚点使用独立但一致的颜色。
- [x] 装饰物不能伪装成可攀爬路线。
- [ ] 远距离能够看见下一段路线的落脚点。
- [x] 路线标识主要存在于世界中，不依赖持续显示大量 HUD 箭头。

## 4. P0：12 分钟地图节奏与统一进化节奏

开局即允许体验基础垂直移动；不要把真正的新玩法拖到数分钟后才开放。地图、尸潮和进化共用一条 12 分钟节奏，但不会在完全固定的秒数机械触发。

### 4.1 唯一的选择仪式

- [ ] 全局只保留“进化三选一”这一种正式选择界面。
- [ ] 原有大选择、小选择、地图选择不再拥有各自的弹窗和时钟。
- [ ] 基础变异、强化、连接、融合、地图能力和传奇规则都由同一个候选生成器产出。
- [ ] 空投开箱直接获得箱体已经预告的短时 Buff，并影响下一次进化；不再弹空投三选一。
- [ ] Boss 奖励转化为进化进度、下一抽品质下限或候选标签倾向；不再立刻弹 Boss 专属三选一。
- [ ] 地图事件通过路线、风险任务和卡牌改变战局；不再暂停游戏要求玩家选择地图分支。
- [ ] 医疗、短时护盾、无限弹药、加速等即时资源仍是拾取物，不进入正式选择界面。

玩家只需要建立一个条件反射：经验条充满时停下来，从三张同品质进化卡里选一张。

### 4.2 选择频率与排队规则

12 分钟目标为 **14～16 次进化，基准 15 次**。这不是 15 个固定闹钟，而是动态经验节奏的目标结果。

| 项目 | 首轮规则 |
|---|---|
| 第一次进化 | 预计 0:22～0:30 出现，目标约 0:25 |
| 常态间隔 | 从上一次选择关闭后计算，通常 32～50 秒 |
| 硬下限 | 两次界面之间至少 25 秒 |
| 最后一次 | 预计落在 9:50～10:30 |
| 完成构筑展示期 | 10:30～12:00 不再生成新选择 |
| 单局次数 | 目标 15，允许因效率落在 14～16 |

- [ ] 将“玩家等级”与“弹出一次选择”解耦；高效率获得的溢出经验进入下一段进化进度，不连续弹多张界面。
- [ ] 若当前实现仍使用约 24～26 次升级选择目标或 TUNE.MUTATION_TIMES 固定大变异时钟，统一进化模式必须停用它们；它们只保留给旧流程 Debug 回退，不能与新导演叠加。
- [ ] 同时最多存在一个 pendingEvolution；不得让玩家关闭一组选项后立刻再看下一组。
- [ ] 达到 25 秒硬下限前即使经验溢出，也只累计进度，不弹界面。
- [ ] Boss 入场、空投争夺、地图结构变化、玩家攀爬关键边缘或高优先级攻击承诺期间，选择可以延迟到安全窗口。
- [ ] 延迟只改变界面出现时机，不吞掉已经赚到的进化。
- [ ] 10:30 前由导演主动把最后一次进化安排出来；10:30 后获得的经验继续计入分数和结算，但不再打断终局。
- [ ] 暂停选择时冻结战斗状态和短时 Buff 计时，避免玩家因为阅读卡牌丢失收益。
- [ ] 记录每次选择实际间隔、延迟原因、溢出经验和最终单局选择次数。

节奏意图：

- 前段选择略快，让构筑拥有方向。
- 中段间隔拉开，让玩家真正使用刚得到的能力。
- 后段高品质概率提高，但总选择次数不暴涨。
- 最后 75～90 秒不再读卡，让玩家只负责享受完成体和终局压力。

### 4.3 0:00～3:00：认识城市并建立构筑骨架

- [ ] 三层基础路线从开局即可到达。
- [ ] 敌人以普通感染者为主，少量展示攀爬行为。
- [ ] 通过尸潮位置自然诱导玩家第一次翻越、上楼和跳楼，不弹出长教学文本。
- [ ] 建筑中层暂时是较稳定的移动通道。
- [ ] 玩家在前 30～45 秒内应完成至少一次明显高度变化。
- [ ] 本阶段预计出现 4～5 次进化，优先建立 2 个基础变异和最早的自动反应。
- [ ] 第一次进化只生成起源卡：三张都是不同基础变异，但仍遵守“先抽品质、三张同品质”。
- [ ] 若第一次抽到稀有或史诗品质，起源卡同时给予对应品质的可见强化；不得偷偷降回普通品质。

### 4.4 3:00～6:00：尸潮向上蔓延并形成第一条回路

- [ ] 正式加入攀爬感染者。
- [ ] 激活第一批滑索、跳板或吊车路线。
- [ ] 第一轮立体空投可以落在中层或屋顶。
- [ ] 触发一个路线开启事件，为现有路线增加捷径。
- [ ] 高处开始出现敌人，但不能突然把屋顶变成不可使用区域。
- [ ] 本阶段预计出现 4 次左右进化。
- [ ] 候选池开始稳定出现稀有连接卡和首批地图能力卡。
- [ ] 到 6:00 时，普通局至少应形成一组“触发—收益—回收”的可重复回路。

### 4.5 6:00～9:00：城市结构改变并追求质变

从事件池半随机选择一至两个持久事件：

- 吊车旋转，形成新的楼间桥梁。
- 广告牌或脚手架倒塌，形成新的登楼斜坡。
- 巴士爆炸或建筑坠物，封堵一条街道路线。
- 感染气体、火焰或积液暂时淹没部分低地。
- 建筑外墙坍塌，打开新的攀爬路线。
- 电力恢复，启动一组跳板、升降平台或滑索。

- [ ] 事件改变真实路线和风险收益，不能只播放动画。
- [ ] 事件发生前有环境声音、灯光和地面提示。
- [ ] 任何封路事件都必须保留至少两条可用逃生路线。
- [ ] 变化后的路线在本局持续存在，让后半局空间记忆真正改变。
- [ ] 本阶段预计出现 4 次左右进化，史诗融合成为可见目标，但不是每局硬发。
- [ ] 玩家可以通过高风险地图行为提高下一次史诗概率或影响候选标签。

### 4.6 9:00～12:00：全立体追杀与完成体展示

- [ ] 攀爬怪、跳跃怪和远程怪组合出现。
- [ ] 地面仍保留高价值经验，不能让所有玩家只在屋顶结束游戏。
- [ ] 精英与空投将玩家引向不同高度。
- [ ] 9:00～10:30 预计出现最后 2～3 次进化，高品质概率达到全局最高。
- [ ] 10:30 后停止新选择，只展示完成构筑。
- [ ] 11:00 后进入明显高压阶段，部分舒适路线被临时压制。
- [ ] 保留“存活 12 分钟”的现有胜利条件，本轮不增加强制撤离任务。
- [ ] 最后一分钟必须允许玩家继续自主选择路线，而不是被单一脚本赶往固定终点。
- [ ] 传奇局可以在终局明显失控；不为了把每局伤害曲线拉齐而临时削弱玩家。

### 4.7 事件导演与界面避让

地图事件不能每局在完全相同的秒数重复。

- [ ] 使用时间窗口而不是唯一固定秒数。
- [ ] 结合玩家所在区域、最近使用最多的路线和当前高度选择事件。
- [ ] 同一局避免连续两次只影响同一层。
- [ ] 事件不能在进化三选一、Boss 入场或玩家正在攀爬关键边缘时突然执行。
- [ ] 每局从事件池选择不同组合。
- [ ] 进化、空投、Boss 与地图事件使用统一的高优先级事件队列，明确谁延迟谁。
- [ ] Debug 可强制触发每个事件并显示触发理由。
- [ ] 记录每局触发了哪些事件、发生时间以及玩家当时所在区域。

## 5. P0：敌人的垂直追击与分层刷新

立体地图成立的底线：

> 高处只能提供暂时的节奏优势，不能成为永久安全区。

### 5.1 三类垂直威胁

#### 攀爬感染者

- [x] 能沿预设攀爬锚点、墙面和脚手架从街道追到中层或屋顶。
- [x] 攀爬前播放抓墙、撞击或嘶吼提示。
- [x] 攀爬过程中可以被玩家射落。
- [x] 到达平台后有很短的恢复时间，避免毫无反应窗口地直接命中玩家。

#### 跳跃感染者

- [x] 能从相邻平台或楼顶跨越缺口扑向玩家。
- [x] 起跳前显示姿态、声音和落点预警。
- [x] 扑击失败后存在可惩罚窗口。
- [x] 不允许从玩家完全看不见的位置无提示瞬移到身边。

#### 远程感染者

- [x] 优先占据相邻屋顶、广告牌或高台。
- [x] 用投射物或范围预警压制长期站桩。
- [x] 攻击前有明显蓄力、弹道和落点提示。
- [x] 作用是迫使玩家换位，不是持续制造无法躲避的伤害。

### 5.2 寻路实现

第一版不要求通用复杂三维 NavMesh，可使用可控的分层路线图：

- [x] 为地图建立 street、mid、roof 三类导航区域。
- [x] 使用 climb、jump、drop、stairs、zip 等连接边。
- [x] 普通地面移动继续沿用当前二维移动逻辑。
- [x] 只有抵达连接节点时进入攀爬、跳跃或坠落状态。
- [x] 连接动作使用固定时长或速度，但视觉位置必须连续。
- [x] 每个连接点标记允许通过的敌人类型。
- [ ] Debug 绘制导航区域、连接边、当前目标层和敌人路径。
- [x] 路线失败时重新选路，不能长期堆积在墙脚。

### 5.3 分层刷怪导演

- [x] 保留当前随时间增长的目标存活数量逻辑，不为展示新系统而无脑增加总怪量。
- [x] 将目标数量按玩家高度和邻近层动态分配。
- [x] 街道敌人从巷口、车辆、商铺遮挡后出现。
- [x] 中层敌人从窗口、脚手架、破墙和楼梯间出现。
- [x] 屋顶敌人从屋顶门、通风口和相邻建筑边缘出现。
- [x] 所有刷新点必须在玩家视线外或被明确环境遮挡。
- [x] 刷新点必须验证可达，不能把普通怪生成在永远下不来的装饰屋顶。
- [x] 玩家快速跨层后，部分追兵继续追踪，部分威胁从目标层前方形成，避免尸潮全部被甩空。
- [x] 不允许直接在玩家身后近距离生成普通怪解决追击问题。

### 5.4 防止屋顶站桩

当玩家在小范围或同一屋顶长时间停留时：

1. 先提高可见的攀爬压力；
2. 再加入跳跃截击；
3. 最后加入远程范围压制。

- [x] 压力逐级增加，不在某个固定秒数突然刷脸。
- [x] 玩家离开区域后压力逐步恢复。
- [x] 普通高处停留本身不惩罚，只有长期无风险站桩才触发导演修正。
- [ ] Debug 显示 antiCamp 状态和当前采用的压制手段。

## 6. P0：三层空间的风险收益、经验与补给

三个高度层必须承担不同职责，否则玩家会找到唯一最优路线并永久重复。地图奖励不仅解决生存问题，也允许玩家通过行动轻微影响下一次统一进化。

| 高度 | 主要价值 | 主要危险 |
|---|---|---|
| 街道 | 敌人最多、经验最多、医疗机会较高；容易形成击杀类标签倾向 | 容易四面包围、路线容易被切断 |
| 建筑中层 | 连续移动最快；容易形成机动、装填、蓄能类标签倾向 | 资源较少、前后夹击 |
| 屋顶 | 视野好、空投和精英奖励更常见；可争取下一抽品质加成 | 远程压制、跳跃截击、出口可能被封锁 |

### 6.1 经验处理

- [ ] 经验球记录所在高度，但吸附时能够跨越楼层。
- [ ] 玩家离开经验所在层后，经验经过短暂延迟自动进入跨层追踪。
- [ ] 大量经验不能永久堆积在楼下造成性能和心理负担。
- [ ] 跨层吸附路径可以穿过建筑几何，但表现上应快速、清楚，不长时间绕路。
- [ ] 经验球不得停在不可站立的墙面、空中或封闭模型内部。
- [ ] 进化进度条清楚显示溢出，但一次只触发一个 pendingEvolution。
- [ ] 统计未被拾取经验量、跨层吸附次数、最长滞留时间和进化间隔。

### 6.2 医疗掉落

- [ ] 继续使用 todo.md 已实现的 medicalNeed 自适应逻辑，不重写另一套系统。
- [ ] 医疗物生成前验证落点可达且可站立。
- [ ] 医疗物不能掉在玩家当前无法返回的封闭层。
- [ ] 屏外指示增加上方、同层、下方信息。
- [ ] 玩家快速跨层时，已有医疗物保持原位置和剩余时间，不瞬移到玩家脚边。
- [ ] 医疗物直接拾取生效，不触发选择界面。

### 6.3 战术空投

- [ ] 继续使用 todo.md 已实现的半动态空投节奏，不恢复成固定三次。
- [ ] 空投落点池覆盖街道、中层和屋顶。
- [ ] 根据玩家当前位置和近期路线，优先选择“前方可争取、但不是脚边白送”的落点。
- [ ] 落点必须存在至少两种到达方式。
- [ ] 空投下降过程在不同高度都能看到光柱、航线或方向标识。
- [ ] 空投标记显示高度差、距离、箱内短时 Buff 图标和下一抽影响。
- [ ] 空投不能穿过屋顶后落进建筑模型内部。
- [ ] 空投与地图事件不能同时封死玩家唯一通路。
- [ ] 开箱后直接获得箱体预告的短时 Buff，例如无限弹药、加速或护盾，不再弹出独立三选一。
- [ ] 高风险屋顶空投额外提高下一次进化的史诗概率；具体规则见 7.8。
- [ ] 玩家可以在接近前判断值不值得冒险，禁止开箱后才随机告知奖励类型。
- [ ] 空投、Boss、地图事件与 pendingEvolution 进入统一事件队列，不能连续抢占玩家注意力。

### 6.4 地图行为不是第四种选择

- [ ] 地图不弹“路线三选一”或“区域三选一”。
- [ ] 玩家通过实际行动表达偏好：去哪里、走什么路线、打什么风险事件。
- [ ] 行为结果只生成一个可见的“下一次进化修正”，包括品质修正或标签倾向。
- [ ] 修正必须在 HUD 上明确显示一次，不允许玩家猜测系统是否生效。
- [ ] 同时最多保留一个品质修正和一个标签修正；新修正覆盖时明确提示。
- [ ] 所有修正只影响下一次进化，用后清除，避免长期权重失控。

## 7. P0：统一进化、品质概率与构筑化学反应

本节替代原先独立的大选择、小选择、地图选择和机动变异卡池。它不是额外系统，而是 todo3 的唯一构筑入口。

玩家的理解应当只有一句：

> **杀怪把进化条打满，系统先决定这次有多稀有，再给三张同品质、都能用于当前构筑的牌。**

### 7.1 进化生成顺序

每次进化必须严格按以下顺序执行：

1. 检查界面硬间隔、安全窗口与 pendingEvolution。
2. 根据当前时间段、保底状态和地图品质修正，抽取本次品质。
3. 根据当前持有变异、前置条件、上限、候选标签和地图状态建立有效池。
4. 在同一品质池内应用构筑相关度和地图标签权重。
5. 生成三张不重复、同品质的有效卡。
6. 玩家选择后立即应用，并记录另两张未选卡。
7. 消耗本次地图修正，更新保底计数和敌人共同进化状态。

- [ ] 禁止先抽三张卡再按颜色比较。
- [ ] 禁止在同一组里出现普通、稀有、史诗混色。
- [ ] 禁止用“稀有卡明显更强”制造只有一个正确答案的假三选一。
- [ ] 三张同品质卡应该回答“这次奇迹往哪个方向发展”，而不是“拿强的还是拿弱的”。

### 7.2 品质定义

| 品质 | 设计职责 | 典型内容 | 玩家感受 |
|---|---|---|---|
| 普通 | 提供新零件或强化单节点 | 新基础变异、分裂 +1、传导阈值 -1、穿透 +1 | 我拿到了下一块拼图 |
| 稀有 | 把两个节点连接成可持续回路 | 击杀回收、命中充能、移动装填、双向触发 | 这套开始自己运转 |
| 史诗 | 融合两个变异或改写枪械、地图行为 | 球状闪电、尸爆裂片、城市电网、攻城骨矛 | 武器形态变了 |
| 传奇 | 打破一个常规上限，制造终局失控 | 连锁可自繁殖一次、弹匣规则重写、地图成为武器 | 这局值得记住 |

品质代表机制深度，不是简单的数值倍率。

- [ ] 普通卡也要可见、可理解，优先使用“多一个、少一次、多穿一个”等离散变化。
- [ ] 稀有卡至少建立一条触发—收益关系。
- [ ] 史诗卡必须改变视觉、声音、目标选择或空间用法中的至少两项。
- [ ] 传奇卡必须改变规则，但仍有生成深度、目标次数或时间预算，不能造成无限递归和性能崩溃。
- [ ] 每个品质都必须准备前置条件不足时可用的起源卡或单节点卡，禁止暗中降级。

### 7.3 首轮品质概率

先使用以下集中配置，后续按数据调整：

| 游戏时间 | 普通 | 稀有 | 史诗 | 传奇 |
|---|---:|---:|---:|---:|
| 0:00～3:00 | 70% | 27% | 3% | 0% |
| 3:00～8:00 | 52% | 33% | 13% | 2% |
| 8:00～10:30 | 38% | 35% | 21% | 6% |
| 10:30～12:00 | 不再生成选择 | 不再生成选择 | 不再生成选择 | 不再生成选择 |

以 15 次进化为基准，首轮目标体验：

- 普通约 8 次。
- 稀有约 4～5 次。
- 史诗约 1～2 次。
- 传奇不是局局出现，目标约 25%～35% 的对局至少出现一次。

- [ ] 概率表、时间分段和目标次数全部进入集中配置。
- [ ] Debug 支持固定随机种子和强制下一次品质。
- [ ] 统计实际品质分布，不根据少量主观试玩立即追着单局结果改概率。

### 7.4 保底：限制坏运气，不限制好运气

首轮保底规则：

- [ ] 连续 3 次普通品质后，下一次至少为稀有；在当前时间段的稀有、史诗、传奇之间重新归一化。
- [ ] 到 7:30 仍未出现过史诗或传奇时，下一次先进行正常品质抽取；若结果低于史诗则提升为史诗，若自然抽中传奇则保留传奇。传奇不因本条获得额外归一化权重。
- [ ] 当前已经拥有两个基础变异、却长期没有相关连接时，提高对应连接卡在所抽品质内部的候选权重。
- [ ] 生成第 4 次进化时若玩家仍不足两个基础变异，本次候选集必须全部为同品质起源卡，保证第 4 次选择结束后成立一组基础反应。
- [ ] 传奇永不保底；它负责制造可记忆的好运，而不是每局打卡奖励。
- [ ] 抽到史诗或传奇后，不降低下一次高品质概率。
- [ ] 不设置“连续两次高品质后强制普通”等反向平衡。
- [ ] 敌人强度导演也不得因为玩家欧皇而即时抬高数值抵消好运；只按既定共同进化规则增加戏剧化敌人。

必须坚持：

> **保底负责救差局，概率负责造神局。**

### 7.5 候选有效性与真正的三选一

基础变异上限：**每局最多 3 个，至少保证 2 个。**

候选生成规则：

- [ ] 第一次进化固定为起源候选集：三张各自提供不同基础变异，品质仍由正常概率抽取。
- [ ] 稀有或史诗起源卡必须包含“获得一个基础变异＋该品质对应的强化”，不能只换卡框颜色。
- [ ] 当玩家已有 3 个基础变异后，不再出现新的起源卡。
- [ ] 至少 2 张候选必须与当前构筑直接相关；第 3 张可以是明确的转向、地图或机动机会。
- [ ] 连接卡只有在相关节点存在，或卡牌自身明确补齐缺失节点时才能出现。
- [ ] 融合卡只有在两个所需基础变异都存在时才能出现。
- [ ] 达到层数上限、无法触发、地图模式不支持或效果已被更高阶规则覆盖的卡不得进入候选。
- [ ] 同一组选项不得出现同一机制的三个纯数值档位。
- [ ] 同一组内不得出现重复卡。
- [ ] 若当前品质的有效池不足 3 张，使用预先设计的同品质通用卡补足；禁止偷偷混入低品质卡。
- [ ] 所有卡使用标签系统：基础变异、触发方式、收益方式、移动动作、地图区域和敌人类型。
- [ ] 构筑相关度影响同品质池内权重，不影响本次已经抽好的品质。

核心分工：

> **运气决定这一局会出现多少次奇迹；玩家决定把这些奇迹装进哪一台机器。**

### 7.6 三层构筑结构

每一套构筑都按三层生长：

1. **基础反应**：持有两个基础变异后自动生效，不额外占一次选择。
2. **稀有连接**：让这两个变异互相回收、维持或放大，形成循环。
3. **史诗融合**：把循环改写成新的武器或空间现象。

因此，即使一局没有任何史诗或传奇，只要玩家拿到两个基础变异，也能拥有明显联动，不会退化成单纯叠数字。

单局强度目标：

| 对局运气 | 应有结果 |
|---|---|
| 差局 | 2～3 个基础变异＋自动基础反应＋若干普通强化，构筑完整但线性 |
| 平均局 | 自动反应＋稀有连接＋约 1 个史诗融合，形成稳定战斗回路 |
| 好运局 | 多个史诗或传奇连续咬合，能力自传播、地图参与输出，终局明显失控 |

### 7.7 六个基础变异与十五组化学反应

首版固定六个基础变异：**爆裂、分裂、过载、骨化、传导、巨化**。任意两两组合都必须成立，不允许出现“抽到了，但这两张彼此没关系”的死搭配。

下表同时定义自动基础反应、稀有连接方向和史诗融合。所有连锁必须有全局生成预算、单目标次数和最大递归深度；表中的“再次触发”默认不能无限循环。

| 组合 | 持有两者后自动发生 | 稀有连接方向 | 史诗融合形态 |
|---|---|---|---|
| 爆裂 × 分裂 | 爆炸时额外释放 1 枚低伤裂片 | 裂片击杀可触发一次小型尸爆 | **追猎尸爆**：爆炸释放追踪裂片，裂片击杀再次尸爆；限制传播深度 |
| 爆裂 × 过载 | 爆炸击杀补充少量过载值 | 满过载提高爆炸范围，爆炸击杀延长过载 | **热核退膛**：满过载换弹释放热震波，并点燃一轮爆炸回路 |
| 爆裂 × 骨化 | 首次穿透目标时植入一枚死亡爆标 | 同一直线多个爆标会依次引爆 | **骨雷贯列**：被穿透的敌人成为骨雷，沿射线方向链式爆炸 |
| 爆裂 × 传导 | 爆炸命中为传导增加 1 层充能 | 闪电击杀小爆、爆炸充能，但每目标只往返一次 | **雷爆闭环**：爆炸与电弧互相接力，在受限目标数内清扫尸群 |
| 爆裂 × 巨化 | 爆炸范围和击退随弹体尺寸增长 | 被巨弹撞飞的敌人碰撞后小爆一次 | **陨星连爆**：巨型冲击爆炸将敌人撞飞，碰撞再爆一次 |
| 分裂 × 过载 | 过载阶段提高分裂弹数量 | 分裂命中维持过载衰减时间 | **蜂群过载**：满过载时裂片变为短程追踪蜂群，命中继续续航 |
| 分裂 × 骨化 | 分裂弹继承一次低伤穿透 | 每次穿透向侧面射出骨针 | **骨树增殖**：骨针继续分叉形成树状弹道，受节点预算限制 |
| 分裂 × 传导 | 分裂弹命中也能为传导充能 | 最后一名电击目标生成电孢子 | **雷孢繁殖**：电孢子命中为下一次闪电充能，并可再繁殖一代 |
| 分裂 × 巨化 | 分裂弹变大并获得明显击退 | 重型碎片额外穿透一次 | **碎星弹群**：巨弹裂成重型弹块，带击退和一次穿透覆盖整条街 |
| 过载 × 骨化 | 高过载时每若干发获得穿透 | 穿透命中延缓过载衰减 | **骨钻洪流**：满过载把弹道收束为持续贯穿的骨钻射流 |
| 过载 × 传导 | 射速越高，传导自然越快充满 | 闪电命中延长过载 | **环形雷暴**：满过载周期性释放环形闪电，命中继续维持过载 |
| 过载 × 巨化 | 持续射击让后续弹体逐步增大 | 停火把积累动量存入下一发巨弹 | **蓄势重炮**：连续射击不断增重，停火后释放一次极限炮击 |
| 骨化 × 传导 | 被穿透的目标短暂成为导体 | 下一次闪电优先沿穿透线传播 | **导骨雷脊**：电弧沿整条穿透路径往返一次，形成清晰线杀 |
| 骨化 × 巨化 | 巨型弹完整继承穿透宽度 | 每若干发生成一枚攻城骨矛 | **街区骨矛**：骨矛贯穿街道，撞墙后产生横向震波 |
| 传导 × 巨化 | 巨弹每次命中提供额外传导充能 | 闪电可以锚定在飞行中的巨弹上 | **行星闪电**：巨弹变为移动球状闪电，飞行中持续向周围放电 |

实现要求：

- [ ] 六个基础变异全部有独立、可辨识的枪口、弹道、命中或敌人状态反馈。
- [ ] 十五组自动基础反应全部可运行。
- [ ] 十五张稀有连接卡全部进入数据表。
- [ ] 十五张史诗融合卡全部进入数据表。
- [ ] 每组融合拥有唯一名称、卡图标、颜色副语言和至少一个明显音效变化。
- [ ] 循环触发统一经过 effectBudget，不允许各卡自行无限生成对象。
- [ ] Debug 能直接授予任意两种基础变异、连接和融合进行单独验证。
- [ ] todo2.md 的枪械表现事件仍是表现出口；本系统发送事件，不重写第二套枪口、后坐或命中反馈。

### 7.8 地图如何进入同一个构筑

地图能力不是额外选择类型，它们是统一进化池中的能力卡；地图行为则改变下一抽。

首批地图能力卡：

| 卡牌 | 建议品质 | 前置 | 效果 |
|---|---|---|---|
| 高压立面 | 史诗 | 传导＋立体地图 | 墙跑经过发光立面时为传导充能；闪电激活墙面电网并短暂打开高价值路线 |
| 尸爆街区 | 史诗 | 爆裂＋可破坏车辆区域 | 被爆裂摧毁的车辆成为二次爆炸源，并改变该街口的战斗路线 |
| 捕食天台 | 稀有 | 弱点击杀能力＋屋顶区域 | 滞空弱点击杀刷新一次空中冲刺；每次滞空最多触发一次 |
| 动能滑轨 | 稀有 | 巨化或过载＋滑索/滑轨 | 滑索、滑铲和高速路线积累动量，离开路线后的下一轮射击获得重击 |
| 动量装填 | 稀有 | 任一翻越/墙跑路线 | 完成翻越、滑铲或墙跑时补充部分弹匣；设短冷却 |
| 坠落震荡 | 稀有 | 立体地图 | 从足够高度落地时产生击退波；不造成玩家落地硬直 |
| 壁行装甲 | 稀有 | 可墙跑表面 | 墙跑期间获得短暂护盾，离墙后迅速衰减 |
| 滑铲火线 | 史诗 | 滑铲＋爆裂或过载 | 滑铲路径留下短时伤害区或强击退带 |

地图风险行为对下一抽的首轮规则：

- [ ] **屋顶空投**：成功开启高风险屋顶空投后，下一次进化史诗概率 +8 个百分点；从普通概率中扣除，传奇概率不下降。
- [ ] **街面高压击杀事件**：完成后，下一次候选的爆裂、击杀、击退标签权重 ×1.8，不改变品质。
- [ ] **连续墙跑路线**：完成指定立面路线后，下一次候选的机动、装填、充能标签权重 ×1.8，不改变品质。
- [ ] **精英路线猎杀**：击杀被标记的跨层精英后，下一次品质至少稀有。
- [ ] 品质奖励叠加上限首轮为史诗 +12 个百分点；标签修正只保留最近一个。
- [ ] 品质加成只从普通概率转移，不降低稀有、史诗之外的既有好运。
- [ ] HUD 用简短文字显示“下一次进化：史诗 +8%”或“下一次更偏向：机动 / 充能”。
- [ ] 这些行为都是可忽略的支线优势；不参与也能完成平均构筑。

地图在这里不再只是战斗背景，而是玩家操纵随机性的实体界面。

### 7.9 玩家与尸潮如何共同进化

共同进化按层级映射，不能让每一张玩家卡都给全体怪物等量加成。

| 玩家获得内容 | 尸潮对应变化 |
|---|---|
| 新基础变异 | 对应主题的普通变体进入刷新池，但只占部分刷新权重 |
| 普通单节点强化 | 只强化玩家，不同步给怪物 |
| 稀有连接 | 通常只强化玩家；少数连接允许增加一个轻量、可预警的精英动作 |
| 史诗融合 | 对应融合精英进入后续波次，并有独立轮廓、声音和攻击预警 |
| 传奇规则 | 普通尸潮不继承；终局 Boss 获得一个主题化终端能力 |

六个基础主题的敌人映射建议：

- 爆裂：死亡前有明显膨胀预警的爆裂感染者。
- 分裂：死亡后分出少量脆弱小体的感染者。
- 过载：短时狂暴冲刺、随后疲劳的感染者。
- 骨化：正面骨甲明显、可从侧后或弱点击破的感染者。
- 传导：彼此靠近时形成可见导电链的感染者。
- 巨化：体型与轮廓显著变大的重型感染者。

约束：

- [ ] 敌人侧变化的目的为“让玩家看见自己改变了世界”，不是把卡牌收益扣回去。
- [ ] 高品质卡必须保持显著净收益。
- [ ] 普通变体、融合精英和 Boss 终端能力分别拥有刷新上限。
- [ ] 任何新增敌人攻击必须接入背后威胁、三维方向和承诺攻击提示。
- [ ] 卡面只用一条短句提示敌人后果；详细解释放在图鉴或暂停面板。
- [ ] 传奇 Boss 能力在出现前通过卡面、Boss 入场和场景效果连续预告。

### 7.10 卡面与品质揭示

目标：玩家在一次暂停内 2～4 秒读懂三张卡的差别。

单张卡结构固定为：

1. 品质与名称。
2. 一句玩家效果，先写触发动作，再写结果。
3. 最多两个前置或关联图标。
4. 一句短小的尸潮后果；若无敌人变化则不显示空栏。
5. 现有构筑关系提示，例如“连接：分裂 → 传导”。

- [ ] 进入界面先用 0.35～0.5 秒揭示本次整体品质，再同时展开三张卡。
- [ ] 三张卡使用同一品质框，但构筑分支图标和主题色不同。
- [ ] 史诗、传奇必须有明显但短促的音画奖励，不拖慢连续试玩。
- [ ] 卡面不展示后台权重、复杂公式或长段 lore。
- [ ] 若由保底提升品质，显示“保底生效”；若由地图行为提高概率，只显示对应地图印记，不伪称必出。
- [ ] 玩家选中后，用一条短动画把新节点接到当前构筑图上。
- [ ] 暂停面板能查看本局构筑图、基础变异、连接、融合和下一抽修正。
- [ ] 新手前两局可以显示一句提示“本次三张同品质，选方向，不用比颜色”；之后自动隐藏。

### 7.11 一局好运样例

用于验证系统是否真的能制造可讲述的对局，而不是所有升级最后都像伤害 +10%：

1. 第一次选择获得分裂。
2. 后续获得传导，自动生效“分裂弹命中也能充能”。
3. 普通强化让分裂数量 +1。
4. 稀有连接让最后一名闪电目标生成电孢子。
5. 史诗融合“雷孢繁殖”让孢子继续给下一次闪电充能。
6. 玩家冒险拿到屋顶空投，使下一次史诗概率提高。
7. 再抽到史诗地图卡“高压立面”，墙跑时整面大楼开始导电。
8. 极小概率抽到传奇，使球状闪电可以自繁殖一次。
9. 终局 Boss 继承一个有充分预警的传导终端能力，但玩家仍明显占优。

最终体验不是“数字更高”，而是：

> **子弹分裂 → 分裂充电 → 闪电生孢 → 孢子再充电 → 墙面变电网 → 球状闪电自繁殖。**

这才是本轮构筑系统要制造的一加一乘法效应。

## 8. P0：进化与三维战斗的可读性、镜头和声音

地图立体化、融合效果增多后，可读性不能靠堆满屏幕箭头和粒子解决。玩家需要同时读懂威胁方向、自己的构筑因果和高品质触发。

### 8.1 构筑因果反馈

- [ ] 普通基础反应使用短小、稳定的视觉语言，不抢夺弱点和攻击预警。
- [ ] 稀有连接触发时，让触发源与收益结果之间出现清楚的方向关系。
- [ ] 史诗融合首次触发时允许一次更强反馈，后续进入较克制的常态反馈。
- [ ] 传奇触发必须独特，但不能用长时间全屏闪白、持续大抖动或遮挡准星。
- [ ] 同一帧多个连锁统一进入表现预算，优先保留玩家枪声、弱点、承诺攻击和首次融合反馈。
- [ ] 击杀记录或短标签能说明主要因果，例如“雷孢 → 传导击杀”，方便玩家理解化学反应。
- [ ] 构筑图中的连接在首次触发时点亮，之后不持续闪烁。
- [ ] 地图能力激活时同时在世界物体和 HUD 上给出同一主题反馈。

### 8.2 三维威胁提示

- [ ] 现有 8 扇区聚合逻辑继续保留。
- [ ] 威胁弧增加上方、同层、下方三种小型符号或形态。
- [ ] 同一方向多个高度的普通怪继续聚合，不为每只怪单独画箭头。
- [ ] 跳跃怪、冲撞怪、Boss 等承诺攻击保留独立高优先级提示。
- [ ] 玩家转向看到威胁后，普通屏外弧及时淡出。
- [ ] 从高处落向玩家的攻击必须显示落点或下落方向。
- [ ] 空投、医疗和精英标记使用同一套高度语言，减少学习成本。
- [ ] 融合精英使用与玩家对应融合相同的主题色，但攻击预警形状必须属于敌人语言，避免误认成友方效果。

### 8.3 环境和敌人声音

- [ ] 攀爬怪在下方抓墙时有可辨识声音。
- [ ] 跳跃怪起跳、飞行和落地使用三个阶段的声音。
- [ ] 远程攻击提供蓄力与弹道声音。
- [ ] 上下方声音具有明显空间位置。
- [ ] 玩家高速移动的风声不能盖住攻击预警、枪声、弱点和击杀确认。
- [ ] 玩家枪声仍按 todo2.md 使用高优先级通道。
- [ ] 构筑连锁声音按基础、连接、融合、传奇分层，并设置同时发声上限。
- [ ] 同一连锁短时间重复触发时使用合并或轻量变体，避免音频糊成一团。

### 8.4 镜头纪律

- [ ] 墙跑只产生轻微、方向确定的镜头倾斜。
- [ ] 禁止翻越时大幅强制摇头。
- [ ] 使用 FOV、风声、速度线、枪模姿态表达速度，不依赖随机相机抖动。
- [ ] 落地冲击主要作用于枪模和短暂镜头压缩，不改变玩家朝向。
- [ ] 空中冲刺不强制拉动玩家瞄准方向。
- [ ] 准星在所有机动状态下保持可读。
- [ ] 史诗和传奇触发不得强行改变玩家视角。
- [ ] 提供“稳定跑酷镜头”设置，降低倾斜、FOV 变化和头部晃动。
- [ ] 连续跑酷、射击和多重融合 60 秒，不应产生明显视觉失控或无法追踪目标的问题。

## 9. 建议代码结构

文件名可以根据现有工程调整，但职责必须拆开，不能把全部逻辑继续堆进 game.js。

建议模块：

- movement.js：Y 轴、重力、跳跃、翻越、抓边、墙跑、冲刺、滑铲与状态机。
- citymap.js：立体地图构建、路线表面标记、落点与空投点。
- nav3d.js：敌人分层导航、连接边与攀爬锚点。
- map-events.js：12 分钟地图事件导演与状态切换。
- evolution-director.js：进化节奏、安全窗口、pendingEvolution、品质抽取、保底与地图修正消耗。
- evolution-pool.js：卡牌定义、前置条件、标签、有效性检查与三张候选生成。
- build-synergy.js：六个基础变异、十五组基础反应、稀有连接、史诗融合与 effectBudget。
- map-build.js：地图能力卡、风险行为、下一抽品质与标签修正。
- horde-evolution.js：普通变体、融合精英和终局 Boss 的共同进化映射。
- render.js：环境、路线提示、构筑触发和三维标记的表现接入。
- tune.js：MOVEMENT、VERTICAL_MAP、VERTICAL_ENEMY、MAP_EVENT、EVOLUTION、RARITY、PITY、EFFECT_BUDGET 等集中参数。

建议核心数据结构：

- EvolutionCard：id、quality、tags、requirements、maxStacks、playerEffect、hordeEffect、presentationKey。
- BuildState：baseMutations、commonNodes、rareLinks、epicFusions、legendaryRules。
- DrawState：evolutionIndex、lastChoiceTime、pending、qualityStreak、hasEpic、mapQualityMod、mapTagBias。
- EffectEvent：sourceId、tags、generationDepth、targetId、budgetCost。
- HordeEvolutionState：activeBaseVariants、fusionElites、bossTerminalRule。

结构要求：

- [ ] 移动模拟、碰撞检测与视觉表现分离。
- [ ] 地图几何、导航数据和动态事件共享同一套区域/连接标识，避免三份坐标各自维护。
- [ ] 玩家和敌人的高度状态使用统一层级定义。
- [ ] 所有动态几何改变后同步更新碰撞、导航和落点验证。
- [ ] 品质抽取与候选生成分为两个明确步骤，并可分别单测。
- [ ] 所有候选先通过 requirements 和 maxStacks 过滤，再应用权重。
- [ ] 所有连锁效果经过统一事件队列和 effectBudget，禁止卡牌直接递归调用另一张卡。
- [ ] 使用固定随机种子可以复现整局品质、候选、地图事件和敌人变体。
- [ ] 对象池继续用于敌人、经验、提示和高频特效。
- [ ] Debug 能单独冻结敌人、地图事件、移动状态或进化导演。

## 14. 完成定义

本文件不是以“地图里出现高楼、玩家可以跳跃、升级卡数量变多”为完成标准。

只有同时满足以下体验，才算改造成立：

1. 玩家会因为尸潮压力主动改变高度。
2. 玩家移动时仍然在持续射击和杀敌。
3. 街道、中层与屋顶各自拥有清晰的风险和收益。
4. 高处提供节奏优势，但不会成为永久安全区。
5. 十二分钟内地图会改变，玩家不能机械重复同一条路线。
6. 玩家只面对一种正式进化三选一，选择节奏不会让人疲劳。
7. 每次三张卡同品质，玩家是在选构筑方向，不是在选颜色。
8. 坏运气被保底托住，普通局不依赖史诗和传奇也能完成构筑。
9. 好运不会被系统追回；少数对局可以形成夸张、值得复述的神仙 Build。
10. 任意两种基础变异都产生自动化学反应，连接和融合继续把它放大。
11. 地图不仅提供移动路线，也允许玩家通过冒险轻微操纵下一抽和构筑形态。
12. 敌人的共同进化让世界回应玩家选择，但不会抵消高品质奖励。
13. 基础移动宽容、连续、有轻度超人感，但不要求专业跑酷操作。
14. 经验、医疗、空投、怪物、构筑反馈和威胁提示全部理解三维高度。
15. 旧平面版本可以独立回退，本次大型改造不会破坏 todo.md、todo2.md 的已有工作。
16. 固定种子、概率模拟和极端连锁压力测试均可复现并通过。

完成每项任务后在本文件中勾选；若实现中发现设计前提不成立，在对应条目下继续追加“实现记录”，写明原因、测量结果、替代方案和 commit，不要删除或改写 Codex 的原始设计条目。

## 15. 实现记录（Claude）

按 §14 要求追加。只记录“设计前提在实现中不成立”或“做法与字面描述有出入”的条目；
逐项勾选见正文。原始设计条目一律不删不改。

### 阶段 A / B（立体城市空间基础与基础机动）

**§3.3 路线结构 —— 导航图需要“同层相邻”这条隐式边。**
首版把连接边只建成显式的 climb / jump / drop / stairs / zip，结果审计立刻发现
街道的四条臂、中层环的四段互不连通：寻路会认为从北街走到东街必须找一个连接点。
原因是 §5.2 说“普通地面移动继续沿用当前二维移动逻辑”，于是同层走动没有被建模成边。
改法：`CITY._autoAdjacency()` 自动为同层、同高、XZ 接触的区域生成双向 `walk` 边。
同时补 `_mirrorLinks()`：stairs / walk 真双向，climb 的反向是 drop（没有坠落伤害，谁都下得来），
jump 的反向在高度差 ≤2.2m 时仍是 jump、否则退化成 drop，zip 与 drop 保持单向。
这一步之后 §3.3 的「每个主要屋顶至少两个出口」不再依赖人工数边维持。
审计：`all_regions_reachable_from_street=all`、`roof_exits>=2 = 6 roofs ok`。

**§2.1 跳板 —— 必须有再装填时间，否则玩家会被无限弹起。**
设计条目只写了“跳板”，没有写再装填。实测（`_citycheck.html` 的落点审计）站在跳板上
会每次接触即弹，玩家永远无法停在板上，且自动化落点判定永不收敛。
增加 `TUNE.MOVEMENT.padRearm = 0.9`。蹦床行为本身保留，这是路线设计的一部分。

**§2.5 状态一致性 —— 滑索期间不得保留 grounded。**
挂索的早退分支没有清 `grounded`，导致下索瞬间还能吃到一次土狼跳，
Debug 面板也会把“空中”读成“在地面”。已在挂索时强制 `grounded=false; coyote=0`。

**审计工具**：新增 `_citycheck.html`（无头运行）。它不是截图检查，而是用几何与导航图
直接证明 §3.3 / §5.3 / §12「路线成立」的判据：跨层连接边数量、全区域可达性、
每个屋顶的出口数与敌人入侵方式、是否存在只有玩家能上的狙击台、刷怪点是否全部可站立、
900 次随机高空坠落是否穿地或落进模型、240 次全向冲刺是否穿墙。
当前结果：全部 PASS（`no_fall_through=0`、`dash_no_clip=0/240`、`landing_always_standable=0/854`）。

### 阶段 C（敌人立体化）

**§5.2「路线失败时重新选路」—— “卡住”必须按进展衡量，不能按耗时衡量。**
首版用“朝连接点走了 N 秒还没到 = 卡住”，结果 55 秒里报出 141 次导航失败。
排查发现全是健康寻路被误判：连接点可能在 20m 外，正常走过去就要 7 秒。
改成记录到目标的距离，只有“距离长时间不再缩短”才算堆在墙脚。
判据同时改成有意义的形式：重选路频率（次/怪/分钟）有界 + 此刻不存在长时间卡死的怪。
实测 2.27 次/怪/分钟、最长卡住 2.25s。

**§3.3 / §5.3 —— 普通尸潮到不了屋顶不是故障，是设计。**
首版把“找不到路”一律计为导航失败。但普通感染者的 navKind 只允许 walk/stairs/drop/jump，
按 §3.3 屋顶的入侵方式本就该由攀爬 / 跳跃 / 远程承担。
改为：无路可走时安静退回二维追击，在下方持续施压，不计失败。
这正是 §5.3「部分追兵继续追踪、部分威胁从目标层前方形成」想要的形状。

**危险区必须同层结算。** 酸池 / 电场原本只比较水平距离，
立体地图下屋顶的酸池会穿过楼板伤到街面的玩家。已加 `hazardSameFloor()`。
