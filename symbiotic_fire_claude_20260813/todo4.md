## 0. 设计纠偏与最终结论

todo3 的地图方向犯了一个上层错误：

> 把“立体、可达、路线丰富”错误地实现成了“到处堆平台、跳板、栏杆、脚手架和连接点”。

当前实现把约 70×70 米的空间塞入中央连廊、停车楼、在建大楼、医院、商场、脚手架、坡道、滑索、跳板与多组动态结构。它通过了“全区域可达”“每个屋顶多个出口”等拓扑检查，却没有通过最重要的第一人称体验检查：

- 玩家看到的是密集积木，不是一座城市。
- 所有东西尺寸相近，建筑、车辆、平台与玩家缺乏清晰尺度关系。
- 路线数量很多，但玩家无法一眼理解主要道路、建筑身份和行动方向。
- 大量移动只是在连续跨越小几何，没有真正改变战斗局面。
- 每栋建筑承担太多玩法，彼此失去差异。
- 自动测试证明地图没有坏，却不能证明地图设计成立。

todo4 的产品目标：

> **制作一座具有真实城市尺度的大型街区。用少量巨大、清楚、有功能的建筑体形成街道、低屋顶和高空捷径，让跑酷跨越真正的城市距离，并让不同空间自然改变尸潮与枪械 Build 的战斗方式。**

设计口令：

> **放大世界，减少东西；延长动作，降低噪声；让建筑本身成为玩法。**

### 0.1 必须锁死的原则

以下是不可被“实现方便”或“多做一点看起来更丰富”破坏的原则：

- [ ] 城市尺度必须可信，不能再次退回 70×70 米的积木竞技场。
- [ ] 先有道路、街区和建筑大体块，再有移动路线，最后才有装饰物。
- [ ] 建筑功能通过整体空间形状产生，不靠贴满小平台制造。
- [ ] 只有地面路线需要完整闭环；低屋顶是半连续路线，高空是稀疏捷径。
- [ ] 玩家在宏观上始终只面对 2～3 个可理解方向。
- [ ] 地图首先服务尸潮射击，其次服务机动展示；不能反过来变成跑酷关卡。
- [ ] 静态灰盒不好玩时禁止加入动态几何、更多装置和视觉装饰掩盖问题。
- [ ] 所有阶段必须由第一人称实机试玩验收；几何与导航测试只能作为底线测试。

### 0.2 可以根据试玩修改的首轮假设

本文中的地图尺寸、建筑数量、滑索数量和路线长度都是首轮灰盒目标，不是永远不许调整的硬编码。

调整纪律：

- [ ] 可以根据试玩整体放大或缩小可玩范围，但不得破坏人与建筑的比例。
- [ ] 可以交换建筑位置和朝向，但必须保留每个区域清楚、不同的主要功能。
- [ ] 可以删除任何路线或装置；删除优先级高于新增。
- [ ] 超出建议几何预算时，必须先写明新增物解决什么体验问题，再实现。
- [ ] 任何参数变化都记录“原值、改值、试玩原因”，避免没有依据地来回调数。

## 2. P0：城市尺度与比例层级

首轮建议的可玩范围约为 220×180 米。外围用无碰撞建筑、道路延伸、雾和灯光把感知城市扩展到至少 500 米，但玩家不需要实际走完整座城市。

### 2.1 首轮尺度参考

以玩家身高约 1.75～1.85 米为基准：

| 元素 | 首轮建议 | 设计意义 |
|---|---:|---|
| 可玩范围 | 约 220×180 米 | 徒步跨图约 25～35 秒 |
| 主干道 | 26～30 米宽 | 尸潮展开、绕圈与长射线 |
| 次级街道 | 16～20 米宽 | 中等压力战斗与转场 |
| 人行道 | 单侧 4～5 米 | 清楚的人车尺度 |
| 小巷 | 7～9 米宽 | 尸潮压缩与穿透、爆炸空间 |
| 低层商铺/民房 | 5～7 米高 | 玩家身高约 3 倍，可快速登顶 |
| 裙楼/停车楼 | 14～20 米高 | 中层连续路线 |
| 可玩高楼 | 30～40 米高 | 玩家身高约 17～22 倍 |
| 远景高楼 | 60～100 米高 | 只负责城市尺度与天际线 |

- [ ] 玩家不能在 5～8 秒内徒步横穿整张地图。
- [ ] 熟练使用冲刺、墙跑、滑索后，跨越主要街区应明显快于徒步。
- [ ] 主街应允许玩家连续跑动至少 8 秒而不撞上无意义障碍。
- [ ] 连续屋顶路线应允许玩家奔跑 5 秒以上，而不是每秒跳一次。
- [ ] 从街面仰视可玩高楼时，必须产生明确的巨大感。
- [ ] 低层房屋、停车楼和高楼之间必须存在一眼可辨的高度层级。
- [ ] 远景楼群不可碰撞、不可伪装成可达区域。
- [ ] 地图边界用街区封锁、废墟、远景延伸或不可进入建筑自然表达，不使用贴脸的四面竞技场高墙。

### 2.2 尺度感的视觉依据

简单大盒子并不等于没有城市感。尺度主要由低成本视觉线索建立：

- [ ] 道路有车道线、斑马线、路沿和人行道。
- [ ] 建筑有按真实楼层间距重复的窗带、门、招牌或结构线。
- [ ] 车辆尺寸、门高和路灯高度与玩家保持一致。
- [ ] 窗户、招牌和楼层线优先使用材质、贴花或实例化，不增加碰撞体。
- [ ] 每类建筑使用不同轮廓和材质语言，而不是只换一块相近的暗色。
- [ ] 玩家在街面可以通过高楼、施工塔或停车楼判断方向，不依赖小地图。

## 3. P0：宏观布局——少量大体块

首轮建议使用四个功能区围绕主干道或十字街组织。下图只表达关系，不锁死具体朝向和坐标：

```text
┌────────────────────┬────────────────────┐
│ 低层商街 5～7m     │ 停车楼 14～20m    │
│ 连续长屋顶          │ 一条宽大连续坡道   │
├──────── 主干道＋十字广场 ──────────────┤
│ 办公塔 30～40m      │ 在建大楼 25～35m  │
│ 裙楼＋长立面        │ 大楼板＋吊臂捷径   │
└────────────────────┴────────────────────┘
```

### 3.1 建筑数量与职责

首轮建议：

- 6～8 个主要建筑大体块。
- 3～4 个真正可玩的建筑。
- 其余建筑只负责围合街道、遮挡刷新和建立城市峡谷。
- 每个可玩建筑只有一个主要移动动词和一个次要战斗价值。

| 区域 | 主要移动动词 | 战斗功能 |
|---|---|---|
| 低层商街 | 翻越后长距离屋顶奔跑 | 快速整理尸潮、弱点击杀与换弹窗口 |
| 停车楼 | 沿宽坡道持续上升或下降 | 把追兵拉成长队，强化穿透与爆炸 |
| 办公塔/裙楼 | 长距离横向墙跑与一次换层 | 快速横穿街区、创造侧射角度 |
| 在建大楼 | 大平台跨越与一道长滑索 | 高风险转场、空投或精英奖励 |

- [ ] 不要求每一栋楼都可上。
- [ ] 不要求每个高度层都形成完整闭环。
- [ ] 不要求每个屋顶都有两个精致出口；可使用一个清楚入口和一个自由跳落出口。
- [ ] 建筑之间必须通过真实街道和城市间距分开，不能相互贴成一个平台团。
- [ ] 每个功能区从远处即可通过轮廓识别。
- [ ] 同一建筑不得同时承担坡道、墙跑、滑索、跳板、脚手架和动态坍塌等全部玩法。

### 3.2 明确删除的旧结构

- [ ] 删除中央十字路口上方的完整悬空连廊环。
- [ ] 删除为了“每层成环”而存在的浮空平台。
- [ ] 删除四层密集脚手架；若保留施工楼层，只保留少量完整大楼板。
- [ ] 删除由集装箱＋小台阶＋雨棚拼成的必经登楼路线。
- [ ] 删除围绕每个边缘布满的高亮栏杆。
- [ ] 删除对路线没有实际影响的装饰性碰撞物。
- [ ] 删除彼此距离过近、功能重复的跳板和滑索。

## 4. P0：三条宏观路线，而不是三张叠层地图

立体感来自高度切换的意义，不来自每个高度都有一套完整路网。

### 4.1 街道主循环

街道是唯一必须完整闭环的路线，也是主要战斗、经验与医疗来源。

- [ ] 主街与次级街道形成一个宽阔、简单、连续的地面循环。
- [ ] 十字广场或开放路口承担最高密度尸潮战斗。
- [ ] 地面路线至少拥有两处自然分流：宽街和小巷。
- [ ] 道路中央只放少量符合交通逻辑的车辆或残骸。
- [ ] 车辆不能随机散布成障碍迷宫。
- [ ] 玩家在地面能够持续射击、倒退、横移和重新组织尸潮。
- [ ] 地面经验收益最高，让玩家有理由主动回到危险区域。

### 4.2 低屋顶半循环

低屋顶负责提供短暂呼吸和连续移动，不做第二张完整地图。

- [ ] 高度主要保持在 5～10 米。
- [ ] 通过一处宽楼梯、坡面、停车楼入口或非常清楚的攀爬面进入。
- [ ] 单段屋顶连续移动距离约 20～40 米。
- [ ] 屋顶之间最多连续跨越一至两次，不制作长串碎平台。
- [ ] 每 25～40 米至少存在一个明显跳回街面的出口。
- [ ] 屋顶资源低于街面，但拥有更好的射击角度或短暂整理时间。
- [ ] 攀爬怪从少量明确入口追上来，不从每条边缘随机冒头。

### 4.3 高空捷径

高空路线是短时高潮，不是永久安全层。

建议关系：

**停车楼顶 → 吊臂或天桥 → 在建大楼 → 长滑索跨街 → 落回地面**

- [ ] 高空路线不是完整闭环。
- [ ] 首轮只设置一条主要高空链。
- [ ] 高空链包含 2～4 个大动作，每个动作跨越真实街区距离。
- [ ] 每个关键动作至少移动 15～40 米，或改变 5 米以上高度。
- [ ] 高空路线最终自然把玩家送回街面或低屋顶。
- [ ] 高处可以放置空投、精英或下一抽奖励，但不能持续刷出最高经验。
- [ ] 玩家在高处停留过久时，用少量可预警远程怪或跳跃怪驱赶，不靠贴脸刷怪。

### 4.4 路线决策密度

- [ ] 任意主要决策点最多同时呈现 2～3 个清楚方向。
- [ ] 关键移动动作之间通常间隔 3～6 秒，让玩家有时间射击和观察。
- [ ] 禁止连续 3 次以上的小平台跳跃。
- [ ] 禁止需要像素级对准的窄梁和边缘。
- [ ] 任何路线标识必须从动作开始前就能看见落点。
- [ ] 如果玩家需要靠背路线才能移动，说明空间语言失败。

## 5. P0：简单空间必须产生明确战斗功能

地图的功能性来自尸潮如何在空间中展开、压缩和追击，而不是来自装置数量。

| 空间 | 尸潮形态 | 自然偏好的构筑 |
|---|---|---|
| 宽主街/广场 | 大面积展开、四周合围 | 传导、分裂、范围控制、移动射击 |
| 长直街 | 形成长射线与纵深 | 巨化、骨化、穿透、重击 |
| 小巷 | 高密度压缩、前后夹击 | 爆裂、尸爆、击退 |
| 停车坡道 | 追兵形成纵向长队 | 穿透、爆炸、持续射击 |
| 低屋顶 | 敌人从少量入口攀爬 | 弱点击杀、换弹、短时蓄能 |
| 高空捷径 | 战斗密度下降、快速转场 | 机动触发、下一轮重击、滞空收益 |

- [ ] 每个主要空间至少有一种可被玩家清楚利用的尸潮形态。
- [ ] 不同 Build 应自然偏好不同空间，但任何 Build 都能在所有区域生存。
- [ ] 地图不能要求拥有指定进化卡才能通过关键路线。
- [ ] 首轮暂时停用或重映射依赖旧几何的地图能力卡。
- [ ] 高压立面、动能滑轨等能力只有在新地图静态空间成立后再接回。
- [ ] 优先让几何自然放大 Build，不用专属卡强行声明“这里与构筑有关”。
- [ ] 地面、高处和狭窄区之间必须形成真实风险收益，而不是单纯高度差。

## 6. P0：几何、碰撞与视觉纪律

### 6.1 首轮几何预算

以下数量是审查阈值，不是为了凑数。少于目标完全可以；超过目标必须说明原因。

| 内容 | 首轮建议 |
|---|---:|
| 主要建筑大体块 | 6～8 |
| 真正可玩建筑 | 3～4 |
| 有功能的路线结构 | 8～12 |
| 滑索 | 1～2 |
| 跳板/加速装置 | 0～2 |
| 主要车辆或残骸 | 10～20，按交通逻辑成组 |
| 有意义的碰撞体 | 目标约 50，超过 70 必须复审 |
| 首轮动态几何组 | 0 |

- [ ] 不能为了达到“丰富”而用满预算。
- [ ] 每个小于 3×3 米的可碰撞物必须说明其战斗或路线作用。
- [ ] 移除后不改变战斗、路线或尺度感的碰撞物应当删除。
- [ ] 路灯、窗框、招牌、窗户、楼层线不参与碰撞。
- [ ] 不用大量矮栏杆限制玩家；城市边缘优先允许自由跳落。
- [ ] 掩体数量服从尸潮视野和移动需要，不按传统掩体射击地图铺设。

### 6.2 可见模型与碰撞模型分离

- [ ] 道路、坡道和楼板使用连续可见表面。
- [ ] 若物理层仍需阶梯近似坡面，阶梯碰撞必须不可见。
- [ ] 更推荐实现斜面、三角面或高度函数碰撞，避免在视觉上暴露 AABB 台阶。
- [ ] 建筑外观可以是简单大盒子，但碰撞轮廓必须稳定、不可卡边。
- [ ] 动态对象必须独立拥有可见节点和碰撞节点，开关时同时切换。
- [ ] 合并 Mesh 前保留动态分组，不能再次出现“碰撞关闭、模型仍显示”。
- [ ] 视觉细节不得改变玩家对可达表面的判断。

### 6.3 路线视觉语言

- [ ] 不再给每一条可翻越边缘描亮线。
- [ ] 一栋建筑只突出一条主要机动路线。
- [ ] 可墙跑长立面用整体材质、灯带或结构节奏表达，不贴满多个小标记。
- [ ] 滑索和跳板仍使用统一颜色，但数量极少、远距离可见。
- [ ] 不可玩建筑与可玩建筑在材质和灯光上有明确区别。
- [ ] 路线提示负责确认玩家已经看见的路线，不负责替代空间设计。

## 7. P0：敌人导航、刷怪与大型场景密度

地图变大不能导致重新回到“场上有怪，但眼前没怪”的问题。解决方式是局部导演，不是重新把建筑挤在一起。

### 7.1 局部战斗单元

- [ ] 将地图划分为若干 40～70 米尺度的战斗单元。
- [ ] 玩家所在单元和相邻单元承担主要活跃敌人。
- [ ] 远处区域保留环境表现，不维持大量无意义活跃敌人。
- [ ] 玩家快速转场后，部分尸潮继续追击，目标区域前方再补充新压力。
- [ ] 转场期间始终保留可射击目标，但不在玩家脚边补怪。
- [ ] 敌人总量根据画面密度与性能调整，不根据地图面积等比例暴涨。

### 7.2 刷新语言

- [ ] 街面敌人从街口、巷口、车辆或建筑转角外出现。
- [ ] 低屋顶敌人从屋顶门、消防通道和少量攀爬入口出现。
- [ ] 高处敌人只从清楚的导航连接进入。
- [ ] 保留背后刷怪最小距离和威胁提示。
- [ ] 不允许在宽阔街道中心凭空生成。
- [ ] 不允许为了追上玩家而在其身后近距离刷新。
- [ ] 刷怪点同时验证遮挡、可达、与玩家距离和目标战斗单元。

### 7.3 简化垂直导航

- [ ] 地面导航保持连续。
- [ ] 低屋顶只在少量入口与街面连接。
- [ ] 高空路线使用有限导航连接，不要求所有敌人通行。
- [ ] 普通感染者不需要进入每一个高点。
- [ ] 攀爬、跳跃和远程怪分别解决追击、截击和站桩，不互相复制全部能力。
- [ ] 玩家离开高处后，无法追上的敌人及时重新分配或回收，避免长期堆积。

## 8. P0：地图变化先使用“热点迁移”

首轮静态地图没有通过前，dynamicMapEvents 在新地图模式下保持关闭。

### 8.1 首轮允许的动态变化

不修改建筑几何，只改变战斗热点：

- 空投落在不同街区或高度。
- 精英占领停车楼、广场或低屋顶。
- 某条街出现临时感染区、火焰或远程压制。
- 高密度尸潮从一个街区向另一个街区转移。
- 下一抽奖励引导玩家冒险进入某一功能区。

- [ ] 热点发生前有清楚预告。
- [ ] 热点距离玩家正常为 12～25 秒机动路程。
- [ ] 热点不强制玩家参加；留在当前区域仍能继续战斗。
- [ ] 热点改变玩家去哪里，不改变玩家如何理解城市结构。
- [ ] 同时只存在一个主要热点。

### 8.2 静态地图通过后的可选大事件

最多先尝试一个：

- 吊臂旋转，形成一条跨街高空捷径；或
- 一处大型路障坍塌，打开新的街道通路。

- [ ] 事件必须从远处可见、影响一条宏观路线。
- [ ] 不制作广告牌小坡、六块攀爬砖、多个升降平台同时出现。
- [ ] 事件加入前后分别进行完整试玩，证明它确实改善后半局路线。
- [ ] 若事件没有改变玩家路径选择，立即删除。

## 9. P1：12 分钟空间节奏

所有基础路线从开局即可使用；时间阶段改变尸潮与热点，不锁住玩家动作。

### 9.1 0:00～3:00：读懂城市

- [ ] 初始热点靠近主街或广场。
- [ ] 玩家在前 45 秒能自然看见低屋顶入口和至少一栋高楼。
- [ ] 尸潮主要从地面展开，让玩家先理解宽街和小巷。
- [ ] 不强制玩家立刻跑完整条高空路线。
- [ ] 首次空投或精英事件可以诱导玩家进入第二个功能区。

### 9.2 3:00～6:00：利用高度整理尸潮

- [ ] 增加攀爬怪和跨层追击。
- [ ] 热点开始在低屋顶、停车楼和街道之间迁移。
- [ ] 玩家能够完整体验一次“街面受压—登高整理—跳回街面收割”。
- [ ] 不增加新的小路线，只增加使用现有路线的理由。

### 9.3 6:00～9:00：跨街机动

- [ ] 空投或精英更可能出现在高风险区域。
- [ ] 跳跃怪和远程怪开始限制长期高处站桩。
- [ ] 玩家有充分理由使用一次完整高空捷径。
- [ ] 如静态地图已经通过，可在此阶段触发唯一大事件。

### 9.4 9:00～12:00：完成体穿越城市

- [ ] 热点更频繁地在不同功能区之间迁移。
- [ ] 尸潮压力覆盖街面、低屋顶与主要高空入口。
- [ ] 10:30 后沿用 todo3 规则，不再弹新进化选择。
- [ ] 最后 90 秒让完成 Build 在不同空间中连续发挥。
- [ ] 不用封死所有路线制造终局压力。

## 12. 验收标准

### 12.1 城市尺度

- [ ] 出生后观察 5 秒，玩家能区分主街、低层建筑、停车楼与高楼。
- [ ] 玩家、门、车辆、楼层、道路和建筑比例可信。
- [ ] 可玩高楼达到玩家身高约十几至二十余倍的视觉感受。
- [ ] 主街像真实街道，而不是几个平台之间的空地。
- [ ] 远景让玩家感到位于更大城市中，且不会误导可达性。
- [ ] 地图边界没有贴脸竞技场围墙感。

### 12.2 空间理解

- [ ] 玩 3 分钟后，玩家能用一句话描述每个主要区域的功能。
- [ ] 不看小地图也能通过地标判断方向。
- [ ] 任一主要决策点不超过 3 个明显方向。
- [ ] 玩家无需记忆路线即可完成街面—登高—回落循环。
- [ ] 不存在视觉上像路线、实际上不可达的装饰结构。

### 12.3 移动价值

- [ ] 玩家能在主街连续奔跑至少 8 秒，不被琐碎几何打断。
- [ ] 玩家能在低屋顶连续奔跑至少 5 秒。
- [ ] 关键机动动作通常跨越 15 米以上距离或 5 米以上高度。
- [ ] 跑酷期间仍能持续射击和理解威胁。
- [ ] 登高能够改变包围状态、射线、尸潮形态或资源机会。
- [ ] 高空路线高效但不能永久安全。

### 12.4 战斗功能

- [ ] 宽街、长街、小巷、坡道与屋顶产生可感知的战斗差别。
- [ ] 至少四种 Build 会自然偏好不同空间。
- [ ] 任意 Build 都能在所有主要区域完成战斗。
- [ ] 地面因经验和密度始终具有吸引力。
- [ ] 大地图没有重新出现“场上有怪、眼前没怪”。
- [ ] 快速跨区后战斗连续，不需要等待追兵数十秒。

### 12.5 几何纪律

- [ ] 没有中央悬空环和长串碎平台。
- [ ] 没有可见的坡道碰撞台阶。
- [ ] 没有随机散放的集装箱和车辆迷宫。
- [ ] 小型碰撞物都能说明明确用途。
- [ ] 动态对象开关同时影响视觉、碰撞与导航。
- [ ] 几何预算超标项已经记录原因并经 Bao 试玩认可。

### 12.6 完整性与性能

- [ ] 默认新地图可以完整游玩 12 分钟并正常结算。
- [ ] 旧立体地图和旧平面地图仍可独立回退。
- [ ] todo3 的统一进化、构筑、共同进化与终局流程没有被破坏。
- [ ] 医疗、空投、经验和敌人不会出现在不可达位置。
- [ ] 大型场景、完整尸潮、融合特效与导航同时运行时达到现有性能目标。
- [ ] 完整一局没有持续增长的对象、监听器、导航任务或定时器泄漏。

## 13. 失败后的正确处理方式

### 如果地图感觉空

正确：

- 提高玩家所在战斗单元的敌人密度。
- 调整刷新方向、热点距离和追击继承。
- 缩短没有战斗意义的道路段。

禁止：

- 重新往路上塞满箱子、栏杆和小平台。
- 把建筑重新挤回玩家身边。

### 如果地图感觉太大

正确：

- 缩短街区之间的空行程。
- 调整可玩范围边界和热点分布。
- 保持建筑、道路和玩家的尺度比例。

禁止：

- 只缩小高楼与街道，重新变回微缩城市。

### 如果机动没有意义

正确：

- 延长一次动作跨越的距离。
- 让路线真实改变包围、射线、奖励或转场效率。
- 删除只起展示作用的小动作。

禁止：

- 再增加更多跳板、滑索和发光平台。

### 如果玩家迷路

正确：

- 强化建筑轮廓、道路主次和远距离落点。
- 减少同时出现的路线。
- 让一个建筑只表达一种主要移动方式。

禁止：

- 在屏幕上增加大量箭头。
- 给每条边缘全部描亮。

### 如果一个区域成为唯一最优解

正确：

- 调整该区域的经验、敌人入口、远程压力或离开成本。
- 强化其他空间的独特战斗价值。

禁止：

- 把所有区域改成相同收益和相同战斗形态。

- 制作开放世界或多个完整城区。

## 15. 完成定义

todo4 不是以“地图面积变大”“高楼变高”“旧功能全部迁移”为完成标准。

只有同时满足以下体验，才算重构成立：

1. 玩家感觉自己位于一座城市，而不是一个由几何体拼成的跑酷场。
2. 建筑、街道、车辆和玩家拥有可信的尺度关系。
3. 世界明显变大，但战斗没有因此变空。
4. 玩家在几秒内能看懂主要道路、建筑身份与移动方向。
5. 大多数射击发生在宽阔、清楚的战斗空间。
6. 每次重要机动跨越真实距离，并改变战斗局面。
7. 街道、长街、小巷、坡道和屋顶自然支持不同 Build。
8. 高处是高效、短暂、有风险的路线，不是永久安全层。
9. 地图用少量大体块形成丰富体验，不依靠增加小几何。
10. 静态地图本身成立，热点和动态事件只是后续放大器。
11. 第一人称人工试玩通过，自动测试只负责证明系统没有坏。
12. 旧地图可完整回退，todo3 已有玩法成果没有被破坏。
