## 0. 上层纠偏

上一轮把武器先收敛成“重炮、风暴、齐射”三个枪匣，虽然比逐弹触发更可感知，但仍然替玩家提前算完了 Build：

- 喷子，本质是并发弹丸、散布、单次耗弹和射击节奏的组合。
- 机枪，本质是弹匣、射速、持续升速与单弹威力的组合。
- 火箭筒，本质是 AOE、高耗弹、低射速与高单发威力的组合。

todo5 不把这些结果直接交给玩家，而是回到更开放的一层：

> **底层使用原子参数实现；卡面向玩家呈现“最小有意义玩法模块”；武器类型只是模块组合后的自然结果。**

“最小有意义玩法模块”既不是“弹速 +10%”这样的细碎参数，也不是“直接变成火箭筒”这样的完整答案。它必须：

- [ ] 单独拿到就能在数秒内被感知。
- [x] 一句话可以读懂。
- [x] 能与当前池中大部分其他模块产生有效反应。
- [ ] 至少能与 3 个其他模块产生改变武器形态的强化学反应。
- [x] 具备明确实现路径、反馈路径和伤害归因。
- [x] 不依赖尚未实现的卡牌文案或占位标记。

设计口令：

> **底层拆成原子，卡面合成模块，玩家组合出枪。**

## 1. 不直接呈现给玩家的底层原子

这些是实现层的统一武器参数，不要求每一项都成为独立卡牌。

### 1.1 资源原子

- 弹匣容量
- 单次耗弹
- 换弹时间
- 弹药返还
- 热量与冷却
- 空仓状态

### 1.2 发射原子

- 射速
- 同时发射弹丸数
- 连发、点射、齐射、蓄力
- 连续射击升速
- 同时发射或依次发射

### 1.3 弹道原子

- 散布角度与散布图案
- 弹体大小
- 弹速、射程、重力
- 穿透
- 弹射
- 追踪
- 分裂
- 平行、扇形、聚焦等弹道布局

### 1.4 命中原子

- 直接伤害
- 弱点倍率
- AOE 半径与伤害
- 击退
- 连锁
- 残留区域
- 延迟结算

### 1.5 条件原子

- 开火、命中、弱点、击杀
- 空仓、换弹
- 冲刺、滑铲、墙跑、滞空、落地
- 与目标距离
- 连续射击时间

以下原子首轮禁止单独作为卡牌：

- [x] 伤害 +X%
- [x] 弹速 +X%
- [x] 弹体大小 +X%
- [x] 击退 +X%
- [x] 射程 +X%
- [x] 单独的散布 +X% 或 -X%

它们可以作为玩法模块内部的构成、品质奖励或后续定向节点。

## 2. 一期八个玩家可见玩法模块

一期先实现 8 个模块。每局最多持有 3 个基础模块；仅三模块组合就有 `C(8,3)=56` 种底座，后续节点与品质继续扩展差异。

数值均为灰盒建议，先验证形态和反应，再调平衡。

### 2.1 齐射

**卡面短句：**一次发射多颗子弹，同时消耗对应数量的弹药。

内部组合：

- 并发弹丸数增加。
- 单次耗弹同步增加。
- 弹丸形成可读的扇形或平行图案。
- 单弹伤害可以适当衰减，但不能让玩家感到“只是数字拆开”。

独立体验：射击从一条枪线变成一面枪线，弹匣消耗明显加快。

### 2.2 爆裂弹

**卡面短句：**命中产生范围爆炸，但每次攻击额外消耗弹药。

内部组合：

- 命中产生 AOE。
- 单次耗弹增加。
- 爆炸中心由玩家命中位置决定，不依赖击杀和尸体附近恰好有怪。
- 对 Boss 保留直击与爆炸价值。

独立体验：玩家会主动把攻击打进密集区域。

### 2.3 穿透

**卡面短句：**子弹贯穿目标，并把已获得的部分效果带到后排。

内部组合：

- 基础贯穿次数。
- 后续目标保留一定伤害。
- 允许继承爆裂、电导、击退等效果，但受统一继承系数和事件预算限制。

独立体验：玩家主动寻找长街、队列和高低差形成的纵深。

### 2.4 分裂

**卡面短句：**主弹命中后生成次级弹，次级弹继承部分已有能力。

内部组合：

- 命中后生成有限数量次级弹。
- 次级弹寻找新目标或按稳定图案展开。
- 次级弹继承部分伤害、弹体属性和载荷。
- 禁止无上限递归分裂。

独立体验：一条枪线在命中后长出第二层覆盖。

### 2.5 重型弹头

**卡面短句：**弹体、伤害与击退大幅提高，但射速下降。

内部组合：

- 弹体增大。
- 单发伤害与击退增加。
- 射速下降。
- 枪声、后坐、曳光和命中反馈同步加重。

独立体验：把不可数的高速小伤害向少量强冲击转换，但不直接预设成某种枪。

### 2.6 超频供弹

**卡面短句：**弹匣和射速提高；持续射击会继续升速。

内部组合：

- 弹匣容量增加。
- 基础射速增加。
- 连续射击产生可感知的升速过程。
- 必须同步制作持续枪声、枪口火焰与枪线密度变化。

独立体验：更长时间维持枪流，并显著改变射击—换弹循环。

### 2.7 弹射

**卡面短句：**子弹结束当前命中后会折向另一个目标。

内部组合：

- 命中后寻找新目标。
- 每次弹射伤害或载荷继承衰减。
- 与穿透共存时，先消耗贯穿，再发生弹射。
- 每枚根弹的弹射次数设上限。

独立体验：攻击会在尸群之间转折，适合分散目标。

### 2.8 动势装填

**卡面短句：**高速移动积蓄动势，强化下一轮射击。

内部组合：

- 冲刺、滑铲、墙跑、空中冲刺和有效下坠积累动势。
- 动势强化“下一轮射击”，不绑定高速枪中难以感知的某一颗子弹。
- 齐射时强化整次齐射；超频时强化短时间枪流；重型化后强化下一次强冲击。
- 必须有枪模发光、准星储能和释放反馈。

独立体验：玩家在“移动蓄能—找角度释放”之间循环，直接连接 todo4 城市地图。

## 3. 模块反应矩阵

定义：

- **S：强化学反应**——产生新的武器形态、覆盖几何或操作节奏。
- **A：有效反应**——明显改变已有模块的效率或作用方式。
- **B：弱反应**——主要是数值叠加，需要额外设计才能保留。
- **X：冲突**——机制互相破坏，默认不能同时出现。

一期目标：每个模块至少拥有 3 个 S，并且与其余模块大部分达到 A 或以上。

| 模块 | 齐射 | 爆裂 | 穿透 | 分裂 | 重型 | 超频 | 弹射 | 动势 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 齐射 | — | S | S | S | S | A | S | A |
| 爆裂 | S | — | S | S | S | A | S | S |
| 穿透 | S | S | — | S | S | A | S | A |
| 分裂 | S | S | S | — | S | A | S | A |
| 重型 | S | S | S | S | — | S | S | S |
| 超频 | A | A | A | A | S | — | A | A |
| 弹射 | S | S | S | S | S | A | — | A |
| 动势 | A | S | A | A | S | A | A | — |

超频和动势目前的 S 数量偏少，允许进入一期的原因是它们分别负责射击节奏和地图机动。但试玩后必须复核：

- [ ] 如果超频最终只是“什么都更快”，降为普通/稀有强化，不占基础模块名额。
- [ ] 如果动势最终只是“移动后伤害 +X%”，降为地图能力卡，不占基础模块名额。
- [ ] 如果任何模块与多数模块只产生数值叠加，必须合并、降级或删除。

## 4. 六组关键反应必须优先成立

以下不是预设枪型，而是验证模块确实能发生化学反应的代表性组合。

### 4.1 齐射 × 爆裂：多点爆破

- [x] 多颗根弹在不同位置制造缩小版爆炸。
- [x] 不把每颗爆炸都按完整倍率复制；单次攻击有统一爆炸预算。
- [x] 增加齐射数量会改变爆破覆盖形状，而不只是总伤害。

### 4.2 爆裂 × 分裂：集束反应

- [x] 主弹命中后分裂，次级弹携带部分爆裂载荷。
- [ ] 玩家可直观看到“大爆点长出多个小爆点”。
- [x] 深度、数量和每秒事件均有硬上限。

### 4.3 穿透 × 爆裂：终点爆破

- [x] 子弹先贯穿队列，在最后有效目标或射程终点产生主爆炸。
- [x] 贯穿负责纵向选择，爆裂负责终点兑现。
- [x] 禁止每穿一个普通敌人都产生一次完整大爆炸。

### 4.4 穿透 × 弹射：折线贯穿

- [x] 子弹先穿过一列目标，贯穿预算耗尽后再折向另一列。
- [x] 新方向必须有明显转折曳光。
- [x] 弹射后的子弹继承较低贯穿次数，避免无限折线。

### 4.5 重型 × 超频：重型机关炮

- [x] 重型降低初始射速，超频通过持续射击逐渐夺回部分速度。
- [x] 最终表现是“从慢重击逐步升成连续重炮”，不是两个百分比相互抵消。
- [ ] 峰值射速仍保持重型冲击可读性。

### 4.6 重型 × 动势：动能炮

- [x] 高速移动积蓄的动势显著放大下一轮重型攻击的弹体、击退和反馈。
- [x] 释放时必须有区别于普通重型弹的视听轮廓。
- [x] 强化整轮攻击，不使用“第 N 发”计数。

## 5. 其余反应的统一规则

以下不要求全部制作独立名称和专属代码；优先通过统一继承规则自然成立。

- 齐射 × 穿透：多条贯穿枪线，形成箭弹墙。
- 齐射 × 分裂：多根弹产生受限次级弹幕。
- 齐射 × 重型：少量高耗弹重型齐射。
- 齐射 × 弹射：多颗子弹分别寻找后续目标。
- 爆裂 × 重型：更大、更强但更慢的爆裂弹。
- 爆裂 × 超频：更密集的小型爆破枪流；爆炸音效和表现必须合并。
- 爆裂 × 弹射：弹射落点携带衰减爆破。
- 爆裂 × 动势：动势提高下一轮爆炸的范围、击退或中心伤害。
- 穿透 × 分裂：次级弹继承低倍率穿透。
- 穿透 × 重型：大弹体长线贯穿。
- 穿透 × 超频：持续枪流钻穿前排。
- 穿透 × 动势：动势提高下一轮贯穿深度与尾迹强度。
- 分裂 × 重型：少量清晰、冲击强的重型碎片。
- 分裂 × 超频：高速枪流周期性释放合并后的分裂波，禁止逐弹对象爆炸。
- 分裂 × 弹射：次级弹获得有限弹射，统一共享派生预算。
- 分裂 × 动势：下一轮分裂增加数量或继承比例。
- 重型 × 弹射：大弹体转向新目标并制造强碰撞反馈。
- 超频 × 弹射：持续命中逐渐提高弹射频率或目标数。
- 超频 × 动势：高速移动帮助保持超频或强化一段枪流。
- 弹射 × 动势：下一轮攻击获得额外弹射次数或更低衰减。

- [x] 上述每一对至少有一项可通过实机观察验证的变化。
- [ ] 如果最终实现只能写成“两个效果同时存在”，矩阵评级降为 B。
- [x] B 级组合不得被包装成史诗融合欺骗玩家。

## 6. 统一继承与事件顺序

所有模块必须共享同一套弹丸谱系，禁止各模块私自生成不受控制的新子弹。

### 6.1 每次根攻击的顺序

1. 根据齐射生成根弹。
2. 应用重型、动势等根弹属性。
3. 命中时先结算直接伤害与穿透。
4. 穿透预算耗尽或满足条件后结算弹射。
5. 分裂生成次级弹。
6. 爆裂等载荷按当前弹丸继承系数结算。
7. 超频只改变发射节奏、弹匣与持续状态，不创建平行伤害系统。

### 6.2 谱系字段

每个弹丸或效果事件至少记录：

- rootAttackId
- parentEventId
- depth
- sourceModule
- damageCoefficient
- payloadCoefficient
- remainingPierce
- remainingBounce
- effectBudgetRemaining

### 6.3 首轮继承原则

- 根弹：100% 直接伤害与载荷。
- 穿透后续命中：逐次衰减。
- 弹射后续命中：逐次衰减。
- 分裂子弹：只继承部分直接伤害和载荷。
- AOE、闪电等反应默认不能继续完整生成另一套反应。
- 所有具体比例进入集中配置，不散落在战斗代码。

数值可以后调，但以下上限必须从第一天存在：

- [x] 单根攻击最大派生弹数量。
- [x] 单根攻击最大效果事件数。
- [x] 单帧和每秒全局效果预算。
- [x] 最大递归深度。
- [x] 同一目标单根攻击的重复命中上限。

## 7. 三选一与 Build 成长

### 7.1 基础模块数量

- [x] 每局最多获得 3 个基础模块。
- [x] 第一次进化固定提供 3 张不同基础模块。
- [x] 第 4 次选择结束前，保证玩家至少拥有 2 个基础模块。
- [x] 中段持续提供第三模块与已有模块深化选项，不强制必须凑满。
- [x] 已满 3 个基础模块后，不再出现新的基础模块。

### 7.2 卡面可读性

基础模块卡面最多显示：

1. 模块名称。
2. 一句主效果。
3. 一句主要代价或限制。
4. 若与已有模块发生 S 级反应，显示一行动态预览：
   - “与你的【分裂】形成：集束反应”
   - “与你的【穿透】形成：终点爆破”

- [x] 禁止把底层十几个原子参数全部展示给玩家。
- [x] 详细数字进入长按/展开说明。
- [x] 动态预览必须来自真实实现状态，不允许只有文案。

### 7.3 品质

- 普通：获得完整基础模块，不存在残废版。
- 稀有：基础模块 + 一项原生离散强化。
- 史诗：基础模块 + 一项改变形态的原生分支。
- 传奇：只打破一条既有规则，必须有明确次数、时间或深度上限。

禁止：

- [x] 史诗爆裂额外赠送不相关的穿透或分裂。
- [x] 用统一 +12% 伤害冒充史诗融合。
- [x] 品质越高只堆更多百分比。
- [x] 不存在战斗消费者的高品质占位卡进入池中。

## 8. 普通与稀有节点的粒度

基础模块负责“改变行为”；后续节点负责“深化这个行为”。

可以作为后续节点：

- 齐射弹丸 +1，但额外耗弹也相应变化。
- 爆裂半径扩大或中心伤害提高。
- 穿透次数 +1。
- 分裂子弹 +1 或继承比例提高。
- 重型射速惩罚减轻。
- 超频升速更快或弹匣继续扩大。
- 弹射次数 +1。
- 动势储存时间或释放规模增加。
- 弱点、换弹、击杀等条件分支。

不得作为基础模块：

- 单独伤害 +10%。
- 单独射速 +10%。
- 单独弹速 +20%。
- 单独击退 +20%。
- 没有反馈变化的纯数值礼包。

## 9. 尸群共同变异

玩家与尸群继续共享主题，但不强求完全相同的公式。

- [x] 玩家获得爆裂后，爆裂尸必须提供可利用和需规避的双向决策；弱点击破可伤害尸群，普通击杀延迟伤害玩家。
- [x] 玩家获得分裂后，裂变尸普通死亡产生幼体，弱点击杀破坏裂变核。
- [x] 玩家获得穿透后，骨甲尸保留正面骨板与侧后/弱点反制。
- [x] 玩家获得超频后，超频尸加速过程必须可见，并存在失速窗口。
- [x] 玩家获得重型后，巨尸仍然是高价值、高压目标，而不是纯血量包。

### 实现中发现并修正的四个问题（都是测出来的，不是猜的）

1. **穿透+弹射时弹射永不触发。** 原本写成「等下一次命中再折」，
   于是一列只有 3 个人时，子弹穿完就直接飞走消失，
   §4.4 的「穿完一列再折向另一列」根本没发生过。
   改成在**贯穿预算耗尽的那一刻**结算弹射（§6.1 第 4 步的原文就是这个意思）。

2. **动能炮（§4.6）等于不存在。** 重型的强化轮只有一发，
   而 1.60 的倍率刚好抵掉「多发变一发」的损失，合起来和两个模块各打各的一样 ——
   正是 §4.5 点名反对的「两个百分比相互抵消」。现在那一发是真正的尖峰。

3. **同一个数写在两个地方。** `MODULES.momentum.heavyDmg` 是死配置，
   代码实际读的是 `MODULE_PAIRS`，所以调它半天不生效。
   已合并为一处 —— §6.3 要求集中配置，**重复即等于没有集中**。

4. **上一条删键后留下 `undefined * 0` 的残留** → `bulletScale` 变 `NaN`
   → 扫掠命中半径是 NaN → 所有 `segCylinder` 返回 -1 → **一发都打不中**，
   而屏幕上枪照开、曳光照飞、没有任何报错。这是最难查的故障形态，
   已在 `applyDerived` 出口加了有限性防线，再出现会立刻报出是哪个字段。

### 偏离设计文档的地方，按 §0.2 的要求记录

1. **没有新开分支**（§10 第 1 条建议 `feature/composable-weapon-modules`）。
   原因：Bao 明确要求「我们有 git 在，不需要分支了，直接做好推送到 main」。
   用户指令覆盖文档建议。隔离改为**功能开关**承担：`composableBuildV2` +
   `?build=old`，A/B 与回滚都不依赖分支。

2. **动势的强化轮规模改成跟着动势强度走**（原设计是固定「下一轮」）。
   原值：固定 1 发。改值：默认 2 发 + 满动势再加 2 发；重型仍是 1 发但那一发是尖峰；
   超频是一段时间窗。原因：实测固定 1 发 +23% 时，动势正好落进 §3 说的
   「只是移动后伤害 +X%」的失败形态，39 发里只有 1 发被强化，肉眼不可能感知。

3. **通用改装只保留 11 项**。剔除了大口径（伤害%）、轻量枪机（射速%）、
   稳定框架（散布%）、双联枪管（并发弹丸 —— 那是齐射的职责）、处决弹头、
   催化增幅、扩散培养 —— 它们都落在 §1 或 §8 的禁用原子里。
   扩散培养的功能改写成了爆裂的 `n_blast_radius` 节点。

### 必须由 Bao 决定的两条（§3 明确要求试玩后复核）

- **超频只有 1 个 S 级反应**，低于 §14 要求的 3 个。
  §3 原文：「如果超频最终只是『什么都更快』，降为普通/稀有强化，不占基础模块名额。」
  实现侧的观察：超频×分裂（合并成周期性分裂波，禁止逐弹生成对象）
  同时改变了覆盖几何和操作节奏，按 §3 对 S 的定义是够格的，
  是这一对最有可能从 A 提升到 S 的候选 —— 但**改矩阵是设计决定，不该由我单方面做**。
- **动势只有 2 个 S**，同样低于 3。§3 原文：「如果动势最终只是『移动后伤害 +X%』，
  降为地图能力卡，不占基础模块名额。」目前它已经不是纯 +X%（强化轮的规模、
  贯穿/分裂/弹射次数、爆炸半径都会变），但 S 的数量确实不够。
