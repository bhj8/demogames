## 0. 问题与设计结论

todo4 已经把地图从约 70×70m 放大到 220×180m，但玩家机动能力基本仍是旧竞技场尺度：

| 项目 | 当前约值 |
|---|---:|
| 地图 | 220×180m |
| 普通移动 | 6.2m/s |
| 地面冲刺 | 约 3.6m |
| 空中冲刺 | 约 4.4m |
| 一次跑墙 | 约 9.5m |
| 一次墙面攀升 | 约 3m |

结果不是“城市太大”这么简单，而是：

> 世界的尺度变了，玩家的一次有效动作仍然很小。

玩家需要用许多零碎动作跨越一个城市距离；机动无法改变包围、射击角度和战斗区域，只剩赶路功能。

本轮不采用“全局速度乘二”，也不把地图整体缩回小竞技场。正确方向是：

1. 城市视觉尺度继续保留。
2. 真正发生战斗的功能空间压缩成紧凑单元。
3. 提高一次完整机动链跨越的距离。
4. 动作之间保留动量，使多个能力连接成一句连续的移动语言。
5. 用少量宏观转场设施连接街区，不用大量小平台填满城市。

设计口令：

> **城市看起来很大，战斗发生得很紧，动作一次跨得够远，连续移动能够改变战局。**

本文数字都是首轮灰盒假设，可根据实机整体调整；优先验证比例关系，不把单个数值写死。

## 2. 三种空间尺度

地图不再把 220×180m 的所有地方当成同一种可玩空间。

| 尺度 | 首轮目标 | 主要作用 |
|---|---:|---|
| 微观动作 | 3～8m | 闪避、翻越、近距离换位 |
| 中观机动 | 12～35m | 跑墙、滑铲跳、连续动作、跨街换角度 |
| 宏观转场 | 40～70m | 滑索、气流、长坡或其他少量跨区设施 |

### 2.1 战斗单元

- [ ] 地图组织为 3～4 个约 35～50m 的主要战斗单元。
- [ ] 每个单元内部拥有地面、中层、屋顶三个清楚层级，但不要求三层全部闭环。
- [ ] 玩家正常机动跨越一个战斗单元约 8～15 秒。
- [ ] 单元之间允许保留城市空距，但必须用明确的中观动作链或宏观设施连接。
- [ ] 玩家不是均匀游遍整张地图，而是在多个紧凑战场之间高速切换。

### 2.2 城市比例调整

- [ ] 远景高楼、天际线和城市纵深继续保留，不因玩法压缩而变回微缩模型。
- [ ] 主要战斗街道优先控制在约 10～16m；可以保留一条 22～28m 的城市主干道作为大场面空间。
- [ ] 常用建筑间跨越距离约 6～10m，保证一次明确动作能够完成。
- [ ] 常用垂直换层以 4～8m 为一段；20～40m 高楼使用露台、裙楼或结构层分段，不要求一次爬完整立面。
- [ ] 不通过重新堆箱子、小平台和栏杆压缩距离。
- [ ] 每次压缩优先移动大体块、缩短空行程或调整可玩边界，保持建筑本身的巨大感。

## 3. P0：重新定义玩家动作单位

首轮灰盒目标：

| 动作 | 当前约值 | 首轮体验目标 |
|---|---:|---:|
| 地面冲刺 | 3.6m | 5～6.5m |
| 空中冲刺 | 4.4m | 6～8m |
| 跑墙 | 9.5m | 12～18m |
| 墙面攀升 | 3m | 4～6m |
| 完整连续动作链 | 未形成 | 25～35m |

- [ ] 普通战斗移动只小幅调整，避免瞄准与走位变得过飘。
- [ ] 大尺度跨越主要来自冲刺、滑铲跳、跑墙、墙跳和空中冲刺，而不是单纯提高常驻跑速。
- [ ] 玩家单次动作的起点、方向和落点在行动前可判断。
- [ ] 不制作需要像素级对准的窄边、墙角和小落点。
- [ ] 低矮边缘自动翻越；墙跑、墙跳和攀爬提供适度吸附与输入宽容。
- [ ] 首轮可尝试约 120～180ms 输入缓存、离地宽容和接墙宽容，具体值根据手感调整。

## 4. P0：连续动量，而不是五个独立技能

目标动作句：

**滑铲起速 → 跳跃 → 跑墙 → 蹬墙转向 → 空中冲刺 → 落地继续滑铲**

- [ ] 滑铲跳继承滑铲的主要水平速度。
- [ ] 进入跑墙时不把已有速度硬重置为固定低速。
- [ ] 离开跑墙后保留大部分出口动量，并允许衔接墙跳或空中冲刺。
- [ ] 空中冲刺在已有方向上追加或修正动量，不把速度突然覆盖成孤立状态。
- [ ] 高速落地成功衔接滑铲时保留明显速度；普通落地再逐渐回到战斗移动速度。
- [ ] 连续动作有清楚的速度、风声、镜头和角色状态反馈，但不使用猛烈随机晃动。
- [ ] 撞墙、擦边和低速误触不应频繁把玩家完全停住。
- [ ] 必须设置速度上限和衰减规则，防止动作叠加无限加速。

操作门槛要求：

- 新玩家可以靠宽容机制自然连出 2～3 个动作。
- 熟练玩家可以稳定维持 5～8 秒连续机动。
- 技巧提高路线效率和战斗收益，不决定玩家是否能通过基本地图。

## 5. P0：每条机动路线必须形成完整语法

一条有效路线包含四部分：

1. **入口**：坡道、雨棚、车辆大体块、低墙或明确墙面。
2. **持续**：跑墙、滑铲、屋顶奔跑或连续下坡。
3. **出口**：墙跳、空中冲刺、滑索或自由落回街面。
4. **兑现**：脱离包围、获得射击角度、抵达热点或拿到资源。

- [ ] 缺少“兑现”的路线视为表演路线，删除或重做。
- [ ] 每条主要路线开始前能看到下一关键落点。
- [ ] 任意主要战斗位置 3 秒内能找到至少一个脱困入口。
- [ ] 关键动作之间通常留出 2～5 秒观察和射击时间。
- [ ] 同时只呈现 2～3 个主要方向，不用大量发光箭头替代空间语言。
- [ ] 宏观转场设施首轮控制在 2～3 条，跨越约 40～70m，并把玩家送入新的战斗状态。
- [ ] 滑索、气流等设施不能成为永久安全区，也不能只是跳过一段无聊道路。

## 6. 战斗、敌人与 Build 联动

机动必须改变战斗，而不仅是减少赶路时间。

- [ ] 跑上中层或屋顶后，玩家获得侧射、纵向穿透或短暂整理尸潮的机会。
- [ ] 跳回街面应能切入高密度经验区，而不是单纯失去高度。
- [ ] 玩家快速跨区时，部分旧尸潮继续追击；目标区前方补充新压力，避免转场后无怪可打。
- [ ] 普通敌人不需要走通所有高空路线；攀爬怪、跳跃怪和远程怪分别承担追击与驱赶。
- [ ] 所有主要路线使用基础能力即可完成。
- [ ] 机动 Build 只改变路线效率、连续时长和战斗收益，不作为地图通行证。
- [ ] todo5 的“动势装填”读取统一动量状态：滑铲、冲刺、跑墙和空中位移自然积蓄，强化下一轮射击；禁止退化成移动后伤害 +X%。
- [ ] 后续机动模块优先产生战斗反馈，例如高速装填、落地冲击、跑墙护盾或滞空齐射，而不是只增加移速百分比。

## 8. 第一轮验收

以下为体验目标，不是纯自动 PASS：

- [ ] 任意主要战斗位置，玩家 3 秒内能看见并进入一条脱困路线。
- [ ] 新玩家在一分钟内至少自然完成一次 2～3 动作衔接。
- [ ] 熟练玩家能维持 5～8 秒连续机动，且过程中没有频繁速度硬重置。
- [ ] 一套完整动作链能跨越约 25～35m，并明显改变包围或射击角度。
- [ ] 一个战斗单元的有效跨越时间约 8～15 秒。
- [ ] 使用最快宏观路线跨越主要城市区域约 15～22 秒；徒步仍明显更慢。
- [ ] 不出现连续 5 秒只有赶路、没有敌人、资源或路线决策的空行程。
- [ ] 玩家不看小地图也能判断入口、下一落点和路线出口。
- [ ] 基础能力能够使用全部主要路线，未选机动 Build 也不会被地图排斥。
- [ ] 机动 Build 会改变玩家选择的路线和射击时机，而不只是让数字变大。
- [ ] 城市依然巨大、建筑比例可信，没有重新变成密集积木竞技场。
- [ ] 完整 12 分钟没有穿墙、卡边、无限加速、落地失控和敌人长期掉队。

人工试玩必须回答：

1. 我是在城市中连续穿梭，还是在大地图里不断按零碎技能赶路？
2. 这次移动有没有让我脱困、换角度或获得收益？
3. 哪段路线最流畅，哪段仍然像跑酷摆设？
4. 普通操作能否自然连招，还是必须背精确节奏？
5. 如果删除某条路线，战斗是否完全没有变化？

## 9. 明确不做

本轮不做：

- 把所有移动速度统一乘二。
- 把 220×180m 地图整体缩回旧 70×70m。
- 为了“连续跑酷”重新堆满小平台、栏杆和脚手架。
- 制作大量滑索、跳板、气流和发光路线。
- 让所有高楼都可以完整攀顶。
- 制作高难度、失败即坠落重来的跑酷关卡。
- 让怪物完整复刻玩家全部机动能力。
- 用机动卡决定基本路线能否通行。
- 在测试走廊手感未通过前全面重排地图。
- 用自动测距代替第一人称人工试玩。

## 10. 完成定义

todo6 完成时，玩家应当获得这样的体验：

> 地图仍是一座尺度巨大的城市，但玩家不会被巨大空间拖慢。每次冲刺、跑墙、墙跳和空中位移都跨越有意义的距离；动作之间能够保留动量并自然连接。玩家在紧凑战场中战斗，再用一条完整机动路线快速切换包围关系、射击角度和城市区域。

只有“城市体量、移动连续性、路线战斗价值”三项同时成立，本轮才算完成。
